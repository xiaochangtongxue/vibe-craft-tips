# 002 · 级联菜单：安全三角区 + 三个延时

原帖：https://x.com/Kubai087/status/2114729985143677258（经典做法常称 menu-aim，最早见于 Amazon 的分类菜单）

## 原理

鼠标从父菜单斜着走向子菜单时，难免擦过下面几行。普通菜单一碰就切换，子菜单就跑丢了。

解法：以指针较早的一个位置为顶点，连到子菜单靠近父菜单那条边的上、下两个角，形成三角形。指针在三角形内，说明正奔向子菜单，路过的行一律不响应；离开三角形，或在某一行停留够久，才切换。再配合延时打开、延时关闭，菜单就稳了。

## 数值

| 机制 | 数值 | 说明 |
|---|---|---|
| 打开延时 | 220ms | 悬停一行 220ms 后生效：文件夹行打开子菜单，普通行收起更深的子菜单；提前离开就取消。触摸立即生效。 |
| 三角顶点 | 倒数第二次 `pointermove` 的位置 | 记录最近两次指针位置，用较旧的一次，避免三角形退化成点。 |
| 作用范围 | 父菜单朝子菜单一侧最后 `min(90px, max(56px, 父菜单宽 × 43%))` | 指针在这条带里且在三角形内，才算安全区。 |
| 安全窗口 | 每 80ms 复查，最长 1200ms | 离开安全区就切换；从开始悬停起满 1200ms 也切换（指针停住不动时也能换到新子菜单）。 |
| 关闭延时 | 360ms | 指针离开触发按钮、所有已打开层级和安全区后，360ms 再整体关闭；及时回来就取消。点击外部立即关闭。 |
| 拖拽悬停 | 420ms | 拖着条目经过文件夹行时，用 420ms 打开。 |
| 解除保护 | — | 指针一进入已打开的子菜单，所有保护解除。 |

高亮必须由组件状态（hovered / active / skipped）驱动，不能靠 CSS `:hover`，否则安全区里被跨过的行仍会亮。

## 结构与键盘

- 输入：一个锚点（点击打开）+ 一棵条目树 `{ label, icon?, href?, children? }`。有 children 的是文件夹行。
- 每层顶部用小标题显示所属文件夹名。
- 键盘：↑↓ 移动；→ / Enter 打开文件夹并聚焦第一项；← 返回上一层；Esc 全部关闭并把焦点还给锚点。
- 角色：`menu` / `menuitem`，文件夹行带 `aria-haspopup` 和 `aria-expanded`。
- 已有菜单组件时，把这套逻辑并入它的子菜单实现，保留 API、键盘和无障碍。

## 几何与动效

- 子菜单向右展开，与父菜单重叠 8px，首行与父行对齐；右侧放不下就翻到左侧，安全区改用子菜单的右边缘。
- 每层宽 210–260px，最大高 `min(420px, 100vh - 24px)`，独立滚动；内边距 6px，圆角 12px，1px 边框，`backdrop-filter: blur(18px) saturate(135%)`。
- 行高 32，圆角 8，行间距 4，padding `0 8px`，图文间隙 8；图标 18px，文字 14px/500，文件夹行带 16px 右箭头。层标题 11px/600 弱化色，padding `4px 8px 2px`。
- 子菜单入场：从 `translateX(-8px) scale(.88, .98)`、透明度 0 开始；透明度 170ms，transform 360ms，`cubic-bezier(.2, 1.45, .35, 1)`。轻微回弹是手感的一部分，别去掉。
- 根菜单从锚点展开：`translateY(-6px) scale(.96, .86)`，原点左上。
- 文件夹图标在子菜单打开时由合上变打开，460ms，`cubic-bezier(.22, 1, .36, 1)`。

| border | `rgba(0,0,0,.14)` | `rgba(255,255,255,.12)` |
| row ink | `#263140` | `#E4E4E4` |
| row hover | `rgba(15,23,42,.07)` | `rgba(255,255,255,.08)` |
| quiet ink | `#7A8491` | `#9A9A9A` |
| chevron | `#94A3B8` | `#8A8A8A` |
| shadow | `0 18px 34px rgba(15,23,42,.12), 0 2px 4px rgba(15,23,42,.05), inset 0 1px 0 rgba(255,255,255,.74)` | `0 18px 34px rgba(0,0,0,.42), 0 2px 4px rgba(0,0,0,.2), inset 0 1px 0 rgba(255,255,255,.06)` |

切换主题时颜色、边框、阴影约 500ms 交叉过渡。

## 工程要求

- 所有时长集中成一组命名常量。
- 点在三角形内的判定写成纯函数（三条边叉积同号，含边上），并加单元测试。
- 可选调试叠层：画出安全区（蓝色 16% 填充 + 虚线描边）和正在计时的计时器。
- 参考实现见 `assets/002-cascading-menu.html`（含调试叠层与计时读数）。

## 验收

- [ ] 从第一行斜着划到子菜单最下面一行，中途经过的行不会抢走子菜单。
- [ ] 在某行停住不动，1.2s 内能切换到它的子菜单。
- [ ] 指针短暂离开再回来，菜单不会关闭。
- [ ] 键盘可以完整走完打开、进入、返回、关闭。
