# 010 · 液态玻璃材质

原帖：https://x.com/Kubai087/status/2117782193108082923（作者开发 Lumno 时研究出的做法）

## 原理

给现成的卡片、播放器、搜索框换上液态玻璃，深浅两种模式各自配好着色浓度。材质拆成 6 个复合层，再加一个按背景亮度自动切换深浅的机制。

## 六层

1. 投影：控制卡片的体积感。
2. 模糊与提亮：模糊背景，同时提高背景的饱和度和亮度，让玻璃更通透。
3. 边缘折射：用 SVG 位移贴图把边缘一圈的背景往里压，越靠边压得越狠，中间保持平整；红光比蓝光多弯一点，形成色散。
4. 着色：一层半透明色彩遮罩，不透明度随背景复杂程度自动调整。
5. 边缘光：左上、右下各一道，再往内侧缩进加一道，让整体更有体积感。
6. 文字着色：浅色玻璃上用正片叠底，深色玻璃上用叠加提亮，文字不是死板的纯色，而是带一点背景的颜色。

另外：在玻璃覆盖的区域读取多个采样点，算出背景平均亮度，低于 0.5 就切换成深色玻璃（配浅色文字）。

## 推荐参数

| | 着色 | 模糊 | 饱和度 | 亮度 |
|---|---|---|---|---|
| 浅色 | 白色 6%–22% | 2px | 180% | 1.06 |
| 深色 | `rgb(20 20 24)` 16%–38% | 2px | 160% | 0.8 |

折射：边宽 44px，边缘偏移 1.1 倍边宽，色散 ±15%。

## 实现要点

- 位移贴图：按玻璃元素的尺寸和圆角，用 canvas 生成一张图。每个像素算到圆角矩形边缘的距离 d，强度 `m = (1 − d / 边宽)²`（中间为 0），方向取边缘的法线；R 通道 = `128 + 127 · nx · m`，G 通道 = `128 + 127 · ny · m`。`feDisplacementMap` 的 scale = 2 × 最大偏移。元素很矮时把边宽限制在短边的约 42%。
- 色散：同一张贴图做三次位移，scale 分别乘 1.15 / 1 / 0.85，各自用 `feColorMatrix` 只留 R、G、B 通道，再用 `screen` 混合回来。滤镜设 `color-interpolation-filters="sRGB"`，`filterUnits="userSpaceOnUse"`，宽高等于元素尺寸。
- 应用：`backdrop-filter: url(#滤镜) blur(2px) saturate(180%) brightness(1.06)`。`backdrop-filter: url()` 目前只有 Chromium 支持；`-webkit-backdrop-filter` 只写模糊、饱和、亮度部分，其他浏览器退回普通毛玻璃。
- 着色层和边缘光分别用 `::before`（背景色）和 `::after`（多重 inset 阴影）。内容放在其上，文字用 `mix-blend-mode: multiply`（浅色）或提亮类混合（深色）。深色玻璃上标准的 `overlay` 会让白字对比度偏低，实践中可以改用 `plus-lighter` 或给主文字保留正常混合。
- 背景复杂度：采样点亮度的标准差越大，着色越浓（在推荐区间内线性映射）。
- 元素被拖动或背景变化时重新采样；尺寸变化时重新生成位移贴图。
- 参考实现见 `assets/010-liquid-glass.html`（三块可拖动的玻璃，可切换自动 / 浅色 / 深色和折射开关）。

## 常见错误

- 只有 `backdrop-filter: blur()`，没有提亮和饱和度，玻璃发灰发闷。
- 整块面积都做位移，画面全部扭曲；折射只应发生在边缘一圈。
- 深浅背景用同一种着色，在亮背景上发灰、在暗背景上发脏。
- 文字用纯黑纯白不做混合，看起来像贴在玻璃上的贴纸。

## 验收

- [ ] 边缘有明显的折射和轻微彩边，中间保持清晰平整。
- [ ] 把玻璃拖到亮区和暗区，深浅自动切换，文字始终清楚。
- [ ] 非 Chromium 浏览器退回为普通毛玻璃，布局不变。
