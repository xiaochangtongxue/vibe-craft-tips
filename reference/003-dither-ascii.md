# 003 · Dither 与 ASCII 参数化效果

原帖：https://x.com/Kubai087/status/2115091203465290087

## 原理

给登录页、卡片、Hero 图加一层可调的纹理，而不是一张做死的图：

- ASCII：把画面切成网格，每格按亮度换成一个字符，从 `.` 到 `@` 越来越密。字号 = 大小，格子疏密 = 间距，明暗对比 = 采样强度；取样区域决定字符画的是暗部还是亮部。
- Dither（有序抖动）：把画面切成像素块，用 4×4 Bayer 矩阵当阈值，把每个颜色通道压成少数几级。像素块 = 大小，纹理尺度 = 间距，采样强度越高，色阶越少、颗粒越重。
- 遮罩：两种效果都叠一层竖向遮罩，让画面退后，读起来像材质而不是噪点。

## 参数（0–100）

| 参数 | ASCII 推荐 | Dither 推荐 |
|---|---|---|
| 遮罩 Mask | 90 | 88 |
| 色调 Color | Original | Original |
| 取样 Sample tones | 暗部 | 不显示 |
| 采样强度 Strength | 100 | 100 |
| 大小 Size | 37（字号 7–24px） | 15（像素块 2–9px） |
| 间距 Spacing | 0 | 0 |

两个滤镜各自保存一套参数，切换时恢复各自的值。

## 通用计算

- `range(v, a, b) = a + (b − a) · v / 100`；亮度 `L = (0.299R + 0.587G + 0.114B) / 255`；`s = strength / 100`。
- 采样：素材按 cover 画进长边约 480px 的小画布，`getImageData` 读取，采样点叠在白底上。选了色板时，先用 256 档查找表把每个像素的 L 映射到色板。
- 每帧均匀取约 12,000 个样本，取 L 的第 8 百分位为 low、第 92 百分位为 high，用于归一化。

## ASCII

- 字符表（由空到满，开头两个空格）：`"  .,:;-=+xX08S#&@"`。
- 等宽字体，字号 `round(range(size, 7, 24))`；容器宽 < 720px 时上限 22。
- 网格步长不能比字形更紧：横向 ≥ 最宽字形 × 1.08；行高 ≥ `@` 高 × 1.12 且 ≥ 字号 × 1.04；横向步长 `range(spacing, 8, 24)`，纵向 `range(spacing, 9, 26)`，取较大者。第一个格子离边缘半个步长。
- 每格：原始色调（暗部模式用 `1 − L`）与 low/high 归一化值按 `0.72 + 0.14s` 混合，再过一条随强度变陡的 smoothstep。色调 ≤ 0.02 跳过；字符 = `chars[round(tone × 16)]`。
- 字色：取样颜色在 HSV 中略提亮、略增饱和；透明度随色调和强度增加，夹在 0.06–0.94。
- 绘制顺序：（重着色后的）原图 → 遮罩 → 字符。

## Dither（Bayer 4×4）

- 像素块 `max(2, round(range(size, 2, 9)))`（< 720px 时上限 7）；图案缩放 `max(1, round(range(spacing, 1, 4)))`；色阶 `max(2, round(range(strength, 8, 2)))`；混合 `blend = range(strength, .32, 1)`。
- 矩阵 `[[0,8,2,10],[12,4,14,6],[3,11,1,9],[15,7,13,5]]`，阈值 `(m + 0.5) / 16`，按 `floor(x/scale), floor(y/scale)` 取。
- 每块取中心点颜色，略推高饱和度，逐通道量化，再按 blend 与原色混合。
- 写进 `容器 / 像素块` 大小的小画布，关闭平滑后放大绘制。
- 绘制顺序：抖动图 → 遮罩。

## 遮罩

- 竖向渐变，色标在顶部、42%、底部。亮色页用白，基础不透明度 54% / 20% / 38%；暗色页用黑，44% / 20% / 50%。
- 遮罩值 v ≤ 50：`base · (v / 50)^1.08`；v > 50：`base + (1 − base) · ((v − 50) / 50)^1.08`。

## 渲染

- 在素材上方叠一个同尺寸、同圆角的 canvas；DPR 上限 1.6，画布上限约 2048×2048。
- 图片：参数变化时重绘，72ms 防抖。视频：播放且在视口内时逐帧重绘（优先 `requestVideoFrameCallback`），原 video 留在下面当源。
- 只作用于指定的素材，不要全局套用。
- 参考实现见 `assets/003-dither-ascii.html`。
