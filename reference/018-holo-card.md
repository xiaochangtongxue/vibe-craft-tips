# 018 · 镭射卡片：随指针倾斜、光随角度走、能翻面的 3D 卡

原帖：https://x.com/Kubai087/status/2121892029403922717（第 1–9 节数值来自原帖随附的 Prompt）

## 原理

把产品里代表身份或拥有的那一张卡（会员卡、门票、徽章、成就、个人名片、套餐档位）做成镭射卡：卡随指针在 3D 里倾斜，镭射层和高光跟着「光点」走，视窗里的图案分层有景深，没人碰时像拿在手里一样轻轻晃，点一下翻到背面，翻转时看得到卡的厚度。

五件事拆开看：

| 部分 | 做法 |
|---|---|
| 倾斜 | 指针位置 → 目标角度，角度用弹簧追目标，离开时轻微回弹；无人操作时目标换成两组正弦叠加的晃动 |
| 光 | 光点跟指针走（无回弹的弹簧），没指针时停在左上方像房间里的灯；镭射层、高光、亮边、徽章都从光点算 |
| 层 | 底色 → 镭射 → 印刷内容 → 高光 → 亮边；印刷在镭射之上，文字始终可读 |
| 景深 | 视窗里每一层有自己的深度 d，按 `d·sin(角度)` 平移，就是真 3D 的投影 |
| 厚度 | 正反两面各离中线半个厚度，中间叠 N 片卡形轮廓；只在翻转时画 |

镭射效果一屏只给一张卡，处处发光就没有意义了。

## 范围

改造用户产品里已有的卡片，不做 demo：在用户的代码、技术栈、组件和设计系统里做，**不改卡片写了什么、点了做什么**。不照搬演示的卡面（品牌、指南针、姓名），用户卡上的内容和图案原样保留，只按第 2 节分层。下面所有数值都是推荐值，第 1–7 节是一套互相配合的 Standard 值，第 9 节是围绕它的预设。数值按 440 × 616 的卡给出，圆角、徽章等卡内尺寸按卡宽等比缩放；倾斜角、景深、厚度、抬起高度是物理量，不缩放。

## 开始前先问用户（一次问一个，列出选项和关键数值，标出推荐，等回答）

先看现状（第 0 节），用几行告诉用户看到了什么，然后依次问。每一问用户都可以选一项、改单个数值或给自己的：

1. **哪张卡**：代表身份或拥有的那一张（会员卡、门票或通行证、徽章或成就、个人或收藏卡、套餐档位），一屏一张。
2. **材质**：第 3 节六种之一（推荐 Prism）；或几种供选择（按档位、稀有度）；或用品牌色——此时从品牌色推出底色、镭射、高光、亮边、侧边色，并把数值列给用户看。
3. **手感**：Quiet / Standard（推荐）/ Lively（第 9 节），或自己的倾斜角、弹簧和晃动幅度。
4. **交互**：跟随指针倾斜（开）、空闲晃动（开）、点击翻面（需要背面：问背面放什么，如二维码、条款）、移动端随手机姿态倾斜（关；iOS 需要授权）。
5. **翻面的话**：厚度（Thin / Standard 推荐 / Thick）和翻转弹簧（第 9 节）。
6. **景深**：卡面图案里哪些部分单独成层、多深（None / Subtle / Standard 推荐）。
7. **背景**：页面保持原样（大多数产品推荐），或在卡后加慢速流体（第 7 节）。

问完用一张表汇总所有选择和对应数值，给出在用户平台上的做法（第 8 节是起点），说明代价和降级，**等用户同意再动手**。

## 0. 从现状出发

- 找到这张卡：组件、尺寸、圆角、图案和内容、放在哪、周围有什么；有没有现成的背面（条款、码、详情）。
- 屏幕怎么画（DOM、原生视图树、GPU 渲染器）、平台版本范围、有没有深色模式、指针和触摸怎么到达这张卡。

## 1. 倾斜和光（Standard）

- 指针在卡上的位置 `(fx, fy)` ∈ 0..1，`nx = 2fx − 1`、`ny = 2fy − 1`；目标 `rotateY = nx · 12°`、`rotateX = −ny · 12°`。卡的父元素 `perspective: 1600px`。
- 角度用弹簧追目标，指针离开时会轻微过冲：`a = 140·(目标 − 角度) − 15·速度`（每秒）。
- 光点 `lx = fx·100%`、`ly = fy·100%`，用无过冲的弹簧跟随：刚度 160、阻尼 `2√160 ≈ 25.3`。指针不在卡上时光点停在左上 (34%, 22%)。
- 悬停强度 `on`：指针在卡上时趋向 1，否则趋向 0，每帧按 `1 − e^(−7·dt)` 逼近；它提亮镭射和高光。
- 空闲晃动：`rotateX = 2.2°·sin(0.9t + 0.6) + 0.8°·sin(2.3t)`，`rotateY = 3.2°·sin(0.7t) + 0.9°·sin(1.9t + 1.2)`（t 秒）；光点随之 `lx = 34% + rotateY·3`、`ly = 22% − rotateX·3`。晃动是弹簧的目标，不是直接写角度，所以从悬停回到晃动也是连续的。
- 触摸：在卡上拖动同样倾斜，只给卡设 `touch-action: none`。手机姿态（选了才做）映射成同样的目标，夹在同样的角度内。
- 卡下阴影：模糊椭圆，黑 60%、模糊 24px、宽为卡宽 84%、高 70px、下沿在卡底下方 30px；向抬起的反方向滑：`x = −rotateY·1.8px`、`y = rotateX·1.2px`。

## 2. 一面的层（从后往前）

| 层 | 内容 |
|---|---|
| 底 Art | 卡自己的底色或图片 |
| 镭射 Foil | 材质（第 3 节），混合在底色上，越靠近光点越亮 |
| 印刷 Print | 卡上印的一切（文字、标志、图案视窗），在镭射之上保证可读 |
| 高光 Glare | 以光点为心的径向渐变：中心白 60%、28% 处白 14%、95%（最远角）处黑 30%；`overlay` 混合；不透明度 `0.35 + on·0.65` |
| 亮边 Rim | 1.5px 的环（`mask` 用 content-box 做 exclude）：一圈很淡的底色，加一个以光点为心、亮边色、到 42% 消失的径向渐变；不透明度 `0.6 + on·0.4`。要随卡转动若隐若现，不能读成一圈实线 |

- 全息徽章（卡上有位置时）：44px 圆片，`conic-gradient(from 角, rgb(255 154 200), rgb(255 224 138), rgb(164 255 207), rgb(143 220 255), rgb(183 155 255), 再重复一遍)`，上面细环（白 35%，每 3.5px 一条 1px），1px 白 60% 外圈。`角 = atan2(ly − 50%, lx − 50%)·1.5 + rotateY·6`。
- 圆角：440 × 616 的卡用 32px，随卡缩放；平台有连续圆角就用（Web 见 004 的 `corner-shape` 渐进增强）。

| Rainbow | 色带随倾斜滑动 | rgb(245 245 247) | rgb(42 44 53) | 285 |
| Pearl | 白卡带粉彩光泽，越近边缘越强 | rgb(23 21 46) | rgb(230 226 242) | 300 |
| Sparkle | 细闪 | rgb(238 240 255) | rgb(26 32 72) | 235 |
| Chrome | 银镜，高光逆着倾斜走 | rgb(27 29 36) | rgb(180 184 194) | 200 |
| Etched | 只在光下看得见的纹 | rgb(237 237 238) | rgb(27 27 30) | 190 |

**Prism**
- 底：`radial-gradient(60% 40% at 50% 0%, rgb(90 150 255 / .55), transparent), linear-gradient(170deg, rgb(13 35 168), rgb(8 18 102) 55%, rgb(22 15 92))`。
- 图案视窗装着光：`radial-gradient(46% 50% at 光点, rgb(255 175 235) 依次 .55 / .4@18% / .22@38% / .09@60% / .02@82% / 透明)`、`radial-gradient(54% 56% at (100% − lx) 74%, rgb(125 225 255) 依次 .45 / .32@18% / .17@38% / .07@60% / .015@82% / 透明)`、`radial-gradient(70% 55% at 30% 100%, rgb(150 255 210 / .3), transparent 75%)`，叠在 `linear-gradient(170deg, rgb(59 98 230), rgb(42 63 191) 55%, rgb(58 47 168))` 上。色标多，读起来是光晕而不是光斑。视窗边框 `rgb(140 170 255 / .1)`，1px 线 `rgb(170 200 255 / .28)`。

**Rainbow**
- 底：`radial-gradient(130% 80% at 25% 0%, rgb(59 62 76), rgb(27 28 35) 62%)`。
- 镭射：`repeating-linear-gradient(115deg, rgb(255 95 126) 0%, rgb(255 184 107) 2.6%, rgb(244 255 107) 5.2%, rgb(107 255 181) 7.8%, rgb(95 210 255) 10.4%, rgb(139 123 255) 13%, rgb(255 107 214) 15.6%, rgb(255 95 126) 18%)`，`background-size: 200%`，位置在光点；上面压一层光栅 `repeating-linear-gradient(125deg, transparent 0 2px, rgb(0 0 0 / .3) 2px 3px)`；`mix-blend-mode: color-dodge`，`filter: brightness(.72) saturate(1.25)`，不透明度 `0.3 + on·0.6`，遮罩 `radial-gradient(farthest-corner at 光点, #000 5%, rgb(0 0 0 / .16) 72%)`。

**Pearl**
- 底：`linear-gradient(160deg, rgb(253 252 255), rgb(241 238 248))`。
- 镭射：`linear-gradient(115deg, rgb(255 196 225) 0%, rgb(201 184 255) 12%, rgb(180 233 255) 24%, rgb(194 255 216) 36%, rgb(255 243 184) 48%, 再来一遍)`，`background-size: 260%`，位置在光点，`multiply`，不透明度 `0.7 + on·0.3`，遮罩 `radial-gradient(70% 60% at 50% 45%, rgb(0 0 0 / .35) 30%, #000 100%)`（中间淡、四周浓，像一圈画框）。
- 高光：`soft-light`，白 90% 到 55% 处消失，不透明度 `0.5 + on·0.5`。亮边：底 `rgb(60 50 120 / .06)`，光白 95%。

**Sparkle**
- 底：`radial-gradient(120% 80% at 75% 5%, rgb(40 51 106), rgb(16 20 43) 65%)`。
- 闪粉：240px 的贴图里约 950 个点，半径 0.45–1.85px（大多是小的），alpha 0.35–1，当作 alpha 遮罩。
- 镭射用 `screen` 混合，两层，每层都被闪粉（第二层偏移 117px, 71px）和 `radial-gradient(at 光点, #000, rgb(0 0 0 / .3) 45%, rgb(0 0 0 / .12))` 共同遮罩：

**Chrome**
- 底：`linear-gradient(125deg, rgb(228 230 234) 0%, rgb(141 147 158) 16%, rgb(246 247 249) 30%, rgb(124 130 141) 46%, rgb(217 220 225) 60%, rgb(148 154 165) 76%, rgb(241 242 244) 100%)`，`background-size: 220%`，位置 `(100% − lx, 100% − ly)`——底色本身逆着光走。

## 4. 翻面（选了才做；Standard）

- 点击、轻点，或聚焦时按 Enter / Space：绕竖轴转 180°，弹簧刚度 70、阻尼 11，约 0.8s 停下、带一点过冲；再按一次转回来。
- 转的时候向观者抬起 `translateZ(|sin(角)|·40px)`；阴影在侧立时最多收窄 45%、下沉 14px。
- 厚度 10px：正面在卡中线前 5px，背面在后 5px 并转 180°，两面都 `backface-visibility: hidden`；中间均匀叠 10 片卡形轮廓，填侧边色。侧边只在翻转时画。
- 背面同样的材质、高光、亮边，光点镜像（`lx → 100% − lx`）；排版用和正面相同的边距。
- 任何改变正面的事（换材质、换内容）都在侧立的那一刻换，永远看不到切换。

## 5. 图案景深（Standard）

- 图案的每一部分有自己的深度 d（在卡面之后为正，之前为负），平移 `x = −d·sin(rotateY + 翻面角)`、`y = d·sin(rotateX)`。这就是真 3D 的结果，不用再乘系数。
- 演示里：最后面的图 90px，指南针表盘 50px，中圈 34px，虚线圈 20px，指针在面前 12px（−12）；四角的印刷字在卡面上不动。最后一层比视窗每边大 100px，边缘永远露不出来。
- 图案能响应就让它响应：指针按弹簧转向指针（`a = 60·角度差 − 5.5·速度`，走短的一边），空闲时 `12°·sin(0.77t) + 6°·sin(2.16t)` 地漂；表盘每秒转 9°，虚线圈每秒反向 18°。小、慢，一个会动的点子就够。

## 6. 节奏和无障碍

- 悬停进出、倾斜、光都连续；翻面约 0.8s 停下。
- 换材质：两面交叉淡化 420ms，或在翻面侧立时换。
- 减少动态效果：不倾斜、不晃、翻面不做动画（直接换，或 200ms 交叉淡化）；光点仍可跟指针；背景静止。
- 卡保持原有角色：链接、按钮还是链接、按钮；背面能用键盘到达并被读屏播报；重要的东西不能只在某个角度看得见。

## 7. 背景（选了才做）

- 卡后光晕：`radial-gradient(closest-side, hsl(材质色相 85% 64% / .3), transparent)`，直径 860px（约两倍卡宽），不透明度 `(0.04 + 0.12·on) / 0.3`。
- 慢速流体：值噪声 fBm（4 个八度，每级乘矩阵 `(1.6, 1.2; −1.2, 1.6)`，振幅减半），扭两次：
  - `p = 位置 / 高 · 1.25 + flow`
  - `q = (fbm(p), fbm(p + (5.2, 1.3) − flow.yx))`
  - `r = (fbm(p + 3.5q + (1.7, 9.2) + 1.3·flow), fbm(p + 3.5q + (8.3, 2.8) − flow))`
  - `f = fbm(p + 3r)`
  - 颜色 `mix(a, b, clamp(2.4f²))`，再按 `clamp(0.95·|q| − 0.35)` 混向 c，乘 `0.5 + 1.1f²`；按到 (50%, 56%) 的距离（y 方向拉伸 1.2）用 `smoothstep(0.82, 0.18, 距离)` 淡到页面色。
  - flow 沿半径 0.33 的圆约 40s 转一圈；整场平移 `(−rotateY, rotateX)·0.008`，跟着倾斜动。
- 调色板 (a, b, c)：

| 材质 | a | b | c |
|---|---|---|---|
| Prism | rgb(10 20 80) | rgb(58 42 156) | rgb(26 108 192) |
| Rainbow | rgb(44 12 64) | rgb(12 68 80) | rgb(90 32 52) |
| Pearl | rgb(51 40 94) | rgb(28 74 74) | rgb(92 44 80) |
| Sparkle | rgb(12 20 56) | rgb(38 51 122) | rgb(74 58 22) |
| Chrome | rgb(24 28 36) | rgb(44 54 70) | rgb(22 64 74) |
| Etched | rgb(13 15 18) | rgb(26 36 40) | rgb(38 42 50) |

- 换材质时调色板约 1s 缓过去。流体按 1/3 尺寸、每秒 30 帧画，再放大；它很软，看不出来。

## 8. 按平台实现（按用户的技术栈和版本核对）

- **Web**：CSS 3D 变换，层是叠在一起的元素加 `mix-blend-mode`。倾斜写在卡自身的 `transform` 上；光点写成**面上的**自定义属性，不要放在父元素上让它继承——改一个继承变量会重算下面所有元素的样式。高光用 2 倍大的层、只改 `transform` 移动；镭射和会动的图案层单独成层（`will-change: transform`）；只画朝向观者的那一面；值没变就不写。所有东西由一个 `requestAnimationFrame` 驱动；流体是一个小 WebGL canvas。
- **iOS（SwiftUI）**：`rotation3DEffect` 加透视，层用 overlay 加 `.blendMode(.colorDodge / .overlay / .multiply)`，渐变位置从光点算，倾斜和翻面用 spring 动画；触摸用 `DragGesture`，手机姿态用 CoreMotion（`CMMotionManager` 的 deviceMotion）。镭射可以用一个 Metal `[[stitchable]]` colorEffect 一次画完。
- **Android（Compose）**：`Modifier.graphicsLayer { rotationX; rotationY; cameraDistance = 12 * density }`，在 `drawWithContent` 里用带 `BlendMode` 的 Brush 渐变，`Animatable` 做弹簧，`pointerInput` 拖动，`SensorManager`（`TYPE_GAME_ROTATION_VECTOR`）取姿态。API 33+ 可用 AGSL `RuntimeShader` 画镭射。
- **Flutter**：`Transform` 配 `Matrix4.identity()..setEntry(3, 2, 0.0006)..rotateX()..rotateY()`，层放 `Stack`，用 `ShaderMask` 或 `CustomPainter` 的混合模式；镭射和流体用 `FragmentProgram`；`sensors_plus` 取姿态。
- **Rust（wgpu、Bevy、egui）**：卡是一个四边形，片元着色器从光点 uniform 算镭射、高光、亮边，整体做 3D 变换；翻面和侧边用第二个四边形和一个薄盒子。

## 9. 预设（围绕 Standard，提问时给出）

| 项 | 选项 |

| 厚度 | Thin 6px（6 片）· **Standard 10px（10 片，推荐）**· Thick 16px（16 片）；抬起分别 30 / 40 / 56px |
| 翻转弹簧 | Soft 55 / 9（更慢、过冲更多）· **Standard 70 / 11（推荐）**· Crisp 110 / 18（快、无过冲） |
| 景深 | None · Subtle（所有深度减半）· **Standard（第 5 节，推荐）** |
| 搭配 | 日常产品求克制：Pearl + Quiet；值得庆祝的时刻：Rainbow、Sparkle 配 Standard 或 Lively |

## 实现要点（demo 的做法）

- **结构**：`perspective` 容器（同时是指针热区，不随卡转，算 fx/fy 用它的矩形）→ 卡（`transform-style: preserve-3d`，transform 每帧写）→ 正面、背面、侧边片。每一面内部是平的（不 preserve-3d），所以 `mix-blend-mode` 只在这一面里混合；景深靠 `translate` 模拟，不是真的 3D 子层。
- **一个 rAF 循环**积分三组弹簧（倾斜、光点、翻面）和指针的角度弹簧；`dt` 夹在 1/30s 内，切回标签页不会弹飞。写样式前把值取整到 0.01 并和上次比，没变就不写。
- **光点变量写在面上**：`--t018-lx / --t018-ly / --t018-on` 只写在正、背两面上，背面写镜像值；`on` 驱动的不透明度在 CSS 里写成 `calc(.3 + var(--t018-on) * .6)`，每种材质只改系数。
- **高光**是 200% 大小的层，渐变中心在它自己中心，用 `translate((lx − 50)/2 %, (ly − 50)/2 %)` 让中心对准光点，只动 transform。
- **亮边和 Prism 的镭射环**都用 `padding` + `mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0); mask-composite: exclude` 抠成环。
- **Sparkle 闪粉**在页面加载时用 canvas 画一张 240px 贴图转 data URL，设成场景上的 `--t018-glitter`（只设一次）；两层镭射各自 `mask-image: var(--t018-glitter), radial-gradient(...)`，`mask-composite: intersect`。
- **只画朝外的一面**：翻面停稳后，背向观者的那一面 `visibility: hidden` 并 `aria-hidden`；转动期间两面都在，由 `backface-visibility: hidden` 裁掉。侧边片只在翻面角离目标超过 0.3° 或还有速度时显示。
- **换材质**：没在翻面时，克隆当前朝外的一面盖在上面，WAAPI 420ms 淡出后移除，下面的面已是新材质；正在翻面时把新材质挂起，等翻面角越过 90°（侧立）再换。
- **翻面**：卡是 `role="button"`、`tabindex="0"`，Enter / Space / 点击都翻；拖动超过 8px 后的点击不算翻面。翻完用 `aria-live` 读出「背面：入场二维码」。关掉翻面时去掉 button 角色。
- **触摸**：热区 `touch-action: none`，`pointermove` 同样驱动倾斜，抬起即视为离开。
- **离屏不花钱**：IntersectionObserver 看不见舞台就停 rAF；流体只在选了「流体」时画，按 1/3 分辨率、30fps。
- **减少动态效果**：角度固定为 0，不晃，翻面直接换面，表盘不转，流体只画一帧；光点仍跟指针。
- demo 加了「速度 ¼×」用来逐帧看弹簧；Sparkle 的镭射不透明度 Prompt 没给，demo 用 `0.5 + on·0.5`；手机姿态倾斜 demo 没做（桌面上无法验证），做法见第 1、8 节。
- 参考实现见 `assets/018-holo-card.html`。

## 常见错误

- 把产品里每张卡都做成镭射，或把镭射放在印刷内容之上，文字被彩光冲掉。
- 倾斜直接等于指针位置、没有弹簧，指针一离开卡就硬跳回 0；或者晃动直接写角度，悬停结束时从当前角度瞬移到晃动位置。
- 光点固定在卡中心，或者高光跟着卡转而不是跟着光点走；没指针时光点回到正中，卡看起来是平的。
- 亮边整圈一样亮，读成一圈描边。
- 把光点写在页面或卡的父元素的继承变量上，每帧重算整棵子树的样式；或每帧重写没变的值。
- 3D 景深用真 `preserve-3d` 子层做，导致面内的 `mix-blend-mode` 失效、和侧边片穿插。
- 两面都常驻显示，或侧边常驻，倾斜 12° 时就露出边；或翻面时能同时看到两面、侧边与面之间有缝。
- 背面的光点没镜像，翻过去后光和指针在相反的两边。
- 翻面中途换材质，看得到正面闪一下。
- 减少动态效果下还在倾斜、晃动、翻面动画；卡原来是链接，改造后点击只会翻面。

## 验收

- [ ] 先报告现状，七个问题一次一个地问，最后用一张表汇总选择和数值，用户同意后才动手；做出来的数值与表一致。
- [ ] 每种选用的材质在四个角和中间看一遍：文字可读，高光不冲掉印刷，亮边不读成实线。
- [ ] 指针离开时有轻微回弹（Quiet 无），空闲晃动连续，光点停在左上。
- [ ] 快速连续翻很多次：从不同时看到两面，侧边和两面之间没有缝；换材质只发生在侧立时或 420ms 交叉淡化。
- [ ] 中端手机上跟得上屏幕刷新率；离屏时不跑循环。
- [ ] 减少动态效果和键盘（Tab 聚焦、Enter / Space 翻面、读屏播报背面）都可用；浅色和深色页面都检查过。
