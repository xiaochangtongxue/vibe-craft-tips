# 001 · 有点击手感的拟物按钮

原帖：https://x.com/Kubai087/status/2114378773655326873

## 原理

平面按钮没手感，是因为缺了实体按键的光影：光从正上方来，顶面略亮、上沿一道反光、下沿一道暗线，底下有贴地的接触影和柔和的抬升影。按下去时这些关系整体反转。气质参考 Lumno、Cloudflare 控制台：冷静、精确、中性灰，不用品牌色、不发光、不用大模糊。

## 层级

| variant | 外观 |
|---|---|
| primary | 近黑石板色，渐变 `#404859 → #273042`，白字 |
| secondary | 凸起的白键，`#FFFFFF → #F4F5F7`，深灰字 |
| tertiary | 浅灰键，`#F3F4F6 → #E7E9EC`，深灰字 |
| ghost | 静止无面；悬停出现很淡的灰底；按下是一个凹陷的「井」 |
| text | 灰字 + 细下划线 + 箭头，悬停时箭头向右推 3px |

## 五层材质（所有实心按钮共用，只换数值，做成 token）

1. 面：180° 线性渐变，顶部比底部亮约 6–8%。
2. 边：1px 实线，比面的底色再深一级。primary `#12161F`，secondary `rgba(15,23,42,.14)`，tertiary `rgba(15,23,42,.10)`。
3. 顶部高光：`inset 0 1px 0` 白色。石板面约 18%，浅色面 85–100%。
4. 底部暗线：`inset 0 -1px 0` 黑色。石板面 22%，浅色面 6%。
5. 两层投影：接触影 `0 1px 2px` + 抬升影 `0 4px 10px -3px`。石板面约 18% / 28%，浅色面约为其三分之一。

inset 层写在按钮自身的 `box-shadow` 里，排在外投影之前，不要用伪元素叠高光：元素自身的 inset 阴影会自动沿内圆角走，任何状态下转角都对得齐。

## 状态

- 悬停：面提亮一级；抬升影扩大到 `0 8px 16px -5px`。
- 按下：`translateY(1px)`；渐变翻转为上暗下亮；外投影收成 `0 1px 1px`；顶部高光换成内阴影 `inset 0 1px 2px` 黑色（石板 40%，浅色 12–16%）；浅色面在下方留一条 `0 1px 0 rgba(255,255,255,.9)`，像按进纸里。
- 静止和按下的阴影层数必须一致（2 个 inset + 2 个外层，不够用 `0 0 0 transparent` 补位），阴影才会过渡而不是跳变。
- 时长：transform 120ms，阴影 140ms，颜色 160ms。
- focus-visible、disabled 沿用项目组件库已有约定。

## 尺寸

- 基准 14px 文字：高 40，左右 padding 18，圆角 10，字重 600，可选 16px 前置图标。
- 石板面文字加 `text-shadow: 0 -1px 0 rgba(0,0,0,.28)`。
- 所有长度随字号缩放：`--u: calc(字号 / 14)`，高度、padding、圆角、边框、图标、按压位移、每个阴影的偏移/模糊/扩散都写成 `--u` 的倍数。md = 14px，lg = 16px。

## 实现要点

- 渐变色要能过渡：用 `@property` 把 `--top`、`--bot` 注册成 `<color>`，再 `transition: --top 160ms, --bot 160ms`。按下时直接写反向渐变 `linear-gradient(180deg, var(--bot), var(--top))`。
- 参考实现见 `assets/001-tactile-button.html`。

## 常见错误

- 用伪元素叠高光，圆角处对不齐。
- 按下态少了一层阴影，按下瞬间跳变。
- 给 primary 加品牌色或外发光，质感立刻变廉价。
- 尺寸只放大字号，阴影和圆角不跟着缩放。

## 验收

- [ ] 五个层级视觉强弱递减，同排对齐。
- [ ] 悬停、按下、松开都平滑过渡，按下有约 1px 的下沉。
- [ ] lg 尺寸下所有阴影、圆角等比放大。
- [ ] 已有组件库时只改 variant / token，API 未变。
