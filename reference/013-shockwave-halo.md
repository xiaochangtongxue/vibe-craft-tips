# 013 · 冲击波光环（含扭曲与通道分离）

原帖：https://x.com/Kubai087/status/2119359092334743735（第 1–7 节数值来自原帖随附的 Prompt）
增强版参考：glimm 0.4（@Nomandsign，MIT，https://glimm.dev），见第 8 节，不属于原帖。

## 原理

触发后（默认是点开或聚焦 AI 输入框），一道淡淡的光环从一处扫过页面然后淡出。光环经过时像透镜一样把页面推开几个像素，带一点色散，分割线和描边短暂反光，到达内容区边缘时内容像透过玻璃斜边一样向边缘拉伸。深浅两种模式各调一套颜色。静止时页面的外观和行为完全不变。

六层，自下而上：

1. 页面快照：把当前页面变成图像，后面各层都从它取样。
2. 透镜扭曲：整个光环是一块透镜，外侧拉伸、内侧压缩。
3. 通道分离：红、蓝通道的位移分别比绿色多、少 8%。
4. 色环：四道色环平滑过渡、随扩散淡出；浅色模式染色，深色模式加光（screen）。
5. 边缘折射：光环只在内容区内；到边缘时内容向边缘拉伸，窗框不动。
6. 边线反光：分割线和描边短暂提亮，深色下更弱。

## 开始前先问用户（一次问一个，给出默认值，等回答）

先看现状（第 0 节），然后依次问：

1. 触发：什么启动光环（点开/聚焦 AI 输入框、快捷键、发送消息、AI 开始回答……），运行中再次触发是重新开始还是忽略。默认：点开输入框，重新开始。
2. 原点和范围：从哪里扩散（AI 输入框、某个按钮、页面底边、点击位置、面板中间），覆盖哪片区域（页面内容区、某个面板、整个窗口）。工具栏永远不被覆盖。
3. 图层：色环（第 3 节）始终开启；透镜、通道分离、边缘折射、边线反光各问一次要不要。透镜、分离、折射需要页面快照（第 6 节），要说明在用户的平台上各自的代价。
4. 配色：四套里选一套，或用品牌色推出四道环的深浅两版；问清应用有哪些模式。
5. 输入框：保持现状（默认），还是换成会弹开、带金属描边的胶囊（第 1 节）。

问完给出在用户平台上的实现方案、代价和降级方式，等用户同意再动手。

## 0. 从现状出发

- 找到 AI 输入框、打开或聚焦它的入口、它所在的页面容器和圆角、压在上面的工具栏，以及有没有深色模式。
- 列出页面用什么绘制（DOM、canvas、原生视图树、GPU 渲染器）和平台版本范围，这决定透镜怎么做（第 6 节）。

## 1. 输入框（只在用户选了胶囊时）

- 静止：胶囊 300 × 44，圆角 22，白色（深色 `rgb(30 30 33)`），1px 细线，左侧星芒图标，占位文字 14px，右侧快捷键提示。水平居中于页面内容，距页面底边 48px。
- 点击：先缩到 97%（90ms），再弹开成 460 × 100、圆角 16 的卡片，从中心长开、底边不动。弹簧 `progress = 1 − e^(−8t)·cos(6t)`（t 以秒计），580ms，略过终点、到时收住。高度和圆角跟同一个 progress。卡片内容一开始就按最终尺寸排好，随卡片长大被露出来，从 30% 处开始淡入。
- 卡片：一行 15px / 22px 行高的输入，左边距 16，光标在前、占位文字紧跟；一条细线；52px 高的工具栏：圆形添加按钮、短分隔、两个选择器（模型、模式），右侧语音和发送，都是 32px。
- 阴影：宽、软、远，不重：`0 0 0 1px rgb(15 23 42 / .09), 0 2px 4px rgb(15 23 42 / .04), 0 28px 64px −16px rgb(15 23 42 / .22)`。没有焦点环，焦点只靠光标表现。
- 金属描边：1px 边框用浅银渐变 `linear-gradient(120deg, rgb(238 240 243), rgb(196 202 210) 28%, rgb(241 243 245) 50%, rgb(188 195 204) 74%, rgb(233 236 239))`（深色 `rgb(74 79 87)` 到 `rgb(51 55 61)`），上面叠一道高光 `conic-gradient(from <角度>, transparent 0 280deg, rgb(255 255 255 / .8) 325deg, transparent 360deg)`。卡片打开时角度在 900ms 内从 −60deg 转到 300deg（ease-out），整条描边的不透明度为 `0.75 · sin(π·t)`。用 `mask: … content-box exclude` 只留边框一圈。
- 收起：320ms ease-in-out 回到胶囊。

## 2. 形状和时间

- 光环是一个从原点长大的圆。默认原点是页面底部的 AI 输入框：圆心在输入框中心的正下方、页面底边以下 650px，所以看到的是一道从底部升起的宽弧。
- 半径 `r = 650 + 800 · (1 − 2^(−9t)) / (1 − 2^(−9))`，1000ms：起点时中线正好在页面底边，开头极快、接近远端时很慢，结束时刚越过页面顶部。
- 换别的原点：时间不变，起点和增量改成「从原点出发、刚好越过区域最远的边」。原点在区域内：圆心放在该点，起始半径 0–40px；原点在边上：圆心放到那条边外侧约区域宽度 2/3 处。
- 强度 `min(1, t/0.03) · (1 − t^2.2)`，结束时归零，在最后慢的那段里淡出。
- 触发即开始；如果输入框要弹开，在弹开开始后 40ms 出发。
- 只在选定区域内：裁到区域形状，工具栏下方是直边，其余是区域自己的圆角（demo 为 12px）。绝不画到浏览器或应用的工具栏上。

## 3. 色环与配色

- 光环宽度上排着四道色环，由内到外各一种颜色。`w = 110px`，`x = (到圆心距离 − r) / w`；第 i 道环中心在 `x = i − 1.5`，权重 `exp(−((x − c)/0.8)²)`，颜色取四色加权平均，相邻环柔和交融。整体一个淡出：`alpha = 强度 · exp(−1.1 · (x/2)²)`。
- 浅色染色：`color = mix(page, ring, alpha·0.24) + ring · alpha · 0.24 · 0.2`。
- 深色加光：`color = 1 − (1 − page) · (1 − ring · alpha · 0.3 · 1.5)`。
- 四套配色（由内到外；深色更亮更饱和，浅色更柔）：

| 配色 | 深色 | 浅色 |
|---|---|---|
| Aurora 蓝紫粉桃 | `80 140 255` `160 110 255` `255 110 180` `255 190 140` | `110 150 255` `180 130 255` `255 130 190` `255 180 120` |
| Halo 橙黄金（逆光镜头） | `255 150 60` `255 190 70` `255 225 120` `255 245 210` | `255 140 50` `255 175 60` `245 200 80` `255 225 150` |
| Frost 薄荷水青带一点青柠 | `80 220 175` `70 195 225` `180 240 150` `235 255 245` | `40 190 150` `50 170 210` `140 210 90` `180 235 215` |
| Spark 紫到金 | `140 100 255` `200 130 255` `255 200 110` `255 235 170` | `130 95 240` `185 125 245` `245 185 80` `250 215 120` |

## 4. 透镜、分离、反光、边缘

- 透镜：整个光环作为一块透镜弯曲页面，不要一环一弯（那样像水波）。`z = 0.75x`，`push = 7px · 2.33 · z · e^(−z²) · 强度`，方向背离圆心，在 `位置 − push` 处读页面。中线外侧拉伸、内侧压缩，范围约等于色环宽度，不更宽。
- 通道分离：只留一丝。红通道按 1.08 倍位移读，蓝通道 0.92 倍；文字必须保持干净。
- 窗框稳住页面：距页面边缘最后 56px 内把透镜淡到 0，边缘保持笔直。
- 边线反光：光环经过处，分割线、边框、标签/卡片/节点的描边向色环颜色（再向白混 20%）提亮，强度 = 光环强度 · `exp(−1.4 · (x/2)²)` · 0.3（浅）或 0.14（深），是微弱的闪光而不是重画的边框；在弯曲后的位置读，反光跟着线走。文字和图标永远不亮。找线的方法：再拍一张只把描边和分割线按原宽度画成白色、其余全黑的快照（无文字、图标、图片、填充、阴影），白处才提亮，1px 边框就只亮 1px。没有快照的 DOM 改造：每帧按元素到光环前沿的距离给每个带边框的元素和分割线设一个 0–1 的 CSS 变量，用它把边框色混向色环色。
- 玻璃斜边：在左右和底边（工具栏下方不做），光环到达处，边缘最后 60px 从更里面 `22 · (1 − d/60)² · 该处强度` 的位置取样，内容向边缘拉伸。光环碰到边缘处加一道细光 `exp(−d/7)`，颜色为色环色向白混 45%。

## 5. 节奏

- 输入框会弹开时：缩 97%（90ms）→ 弹开（580ms），描边高光转一圈（900ms）；光环在弹开开始后 40ms 出发，跑 1000ms。不弹开时触发即出发。
- 深浅切换时，光环颜色跟页面一起交叉淡化，不要硬切。
- 减少动态效果：不弯曲、不分离、不反光；光环在原地以一半强度淡入淡出，600ms。
- 只在光环运行时绘制，静止时什么都不画。

## 6. 按平台实现（起点，不是规定）

光环本身（色环、边线和边缘的光）只是一层叠加，哪里都能做；透镜需要把页面当成可取样的图像。

- Web（demo 的做法）：页面上盖一张 WebGL2 画布，一次片元着色从快照画完全部效果。像素比上限 2；画布不接收指针事件，静止时隐藏。
- Web 拿快照：
  - HTML-in-Canvas（WICG）：画布以页面为子元素，用 `drawElementImage()` 绘制或直接上传为纹理，实时且是真实浏览器渲染。Chromium 里在 `canvas-draw-element` 开关后，Chrome 157 起默认开启；Firefox、Safari 暂无。有就用。
  - SVG foreignObject（html-to-image、modern-screenshot）：浏览器自己渲染克隆，保真；图片和字体必须内联或同源，根节点要有背景色，`backdrop-filter` 不可靠。点击时拍一次（几十到几百毫秒），然后再动画。
  - html2canvas（或 html2canvas-pro）：自己重新实现 CSS，现代效果（backdrop-filter、部分渐变、oklch）可能画错。最后手段。
  - 没有快照：只在透明画布上画色环（浅色正常 alpha；深色 `mix-blend-mode: screen` 或 `plus-lighter`），不做透镜。只在 Chromium 里可以用 `backdrop-filter` 指向带 `feDisplacementMap` 的 SVG 滤镜做弯曲，有代价。
- iOS（SwiftUI，iOS 17+）：效果写成 Metal `[[stitchable]]` 函数，对页面视图用 `.layerEffect(shader, maxSampleOffset: CGSize(width: 30, height: 30))`，可以在弯曲位置取样并加色，实时。半径和强度由 `TimelineView` 或可动画值驱动。iOS 17 以下：`AngularGradient` + 模糊叠加，不做透镜。
- Android（API 33+）：AGSL 写成 `RuntimeShader`，内容作为名为 content 的 uniform shader，`view.setRenderEffect(RenderEffect.createRuntimeShaderEffect(shader, "content"))`（Compose：`Modifier.graphicsLayer { renderEffect = …asComposeRenderEffect() }`），每帧更新 uniform。33 以下只做叠加。
- Flutter（Impeller）：`FragmentProgram` + `ImageFilter.shader` 放进裁剪到页面的 `BackdropFilter`；引擎把内容作为 sampler 0、尺寸作为第一个 vec2 传入。用 `FlutterFragCoord()`，GLES 上翻转 y，检查 `ImageFilter.isShaderFilterSupported`，不支持就只做叠加。
- Rust：把 UI 渲染到离屏纹理，再用移植到 WGSL 的同一个着色器画一个全屏 pass。wgpu 手写（渲染目标带 `TEXTURE_BINDING`、全屏三角形、uniform 放一个 buffer）；Bevy 写自定义后处理节点（`ViewTarget::post_process_write()`）；egui / iced 通过渲染器的 wgpu 回调先渲染到纹理再合成。
- Electron、Tauri：走 Web 路线；Electron 也可以用 `webContents.capturePage()` 拍快照。

## 7. 实现要点（demo 的做法）

- 画布放在页面区之上、输入框之下：输入框保持清晰可交互，光从它背后升起；快照只拍页面区，不含输入框，所以输入框弹开不会让快照失效。
- 快照：克隆页面区，把每个元素的 `getComputedStyle` 全量写成内联样式，序列化进 `<foreignObject>`，`Image.decode()` 后画到 canvas 再上传纹理。同一份样式再加 `color/背景/阴影 → 透明、border-color → #fff`、根节点黑底，得到描边图。页面里不要用伪元素（克隆不带 `::before/::after`），字体用系统字体（SVG 图像里加载不到网页字体），否则快照和 DOM 对不齐，出现时会跳一下。
- 快照失效：页面区 `MutationObserver` + `ResizeObserver` 标记失效；主题切换要等 300ms 颜色过渡结束，读样式时再临时加一个 `transition: none !important` 的类，保证读到终值。区块进入视口后在空闲时预拍，点击时光环能按时出发。
- 着色器里所有尺寸用 CSS 像素算（`gl_FragCoord / dpr`，y 向下），快照纹理不翻转，`uv = p / size` 直接取样。
- 结束时隐藏画布、停掉 rAF；`drawImage` 了 foreignObject 的画布被判为跨源时 `texImage2D` 会抛错，捕获后退回只叠色环。
- 参考实现见 `assets/013-shockwave-halo.html`（原版 / 增强切换、四套配色、深浅、¼ 速慢放）。

## 8. 增强版（非原帖，对照 glimm 0.4 改进）

评论区推荐的 glimm 读起来更「亮眼」，拆开它的着色器和演示，差别在三点：颜色像箔片一样跟着表面起伏变化；光带有体积（固定光源下的高光）；光带有意义——旧页面在前、新页面在后，光带经过就是内容更新的那一刻，而且它跟着请求走：请求进行时蓄力，结果到了才放出去。glimm 的短板也明显：浅色下大面积饱和色会盖住文字，也没有透镜、边缘和边线这一层物理感。增强版保留原帖第 1–7 节全部做法，只加下面几项：

- 体积高光：把透镜那条曲线当高度场 `h = e^(−z²)`，法线取 `n = −dir · dh/dx · 0.9 · 强度`；光从上方来，`tilt = (n · 上) / 0.5`，限制在 ±1。浅色下染色强度乘 `1 + 0.5·tilt`，再按 `pow(max(tilt,0),3) · 强度 · 0.22` 混向色环色；深色下额外 screen 一层 `mix(ring, 白, .55) · hl · 0.28`。效果是弧顶迎光的前沿最亮，两侧渐暗，光环像一道凸起的玻璃。
- 虹彩流动：取色坐标 `xs = x + 0.45 · sin(3θ + 2.4·秒) + 0.6·tilt`（θ 为相对圆心的方位角，正上方为 0），淡出仍按原来的 x。颜色沿弧线缓慢流动、随坡面偏移，不再是四道同心的条纹。
- 文字保护：浅色染色从 0.24 提到 `0.32 · mix(0.45, 1, 页面亮度)`，深色 0.45 提到 0.52。颜色更饱和，但深色文字处染得少，字不会被色块盖住。
- 跟着结果走（替换触发）：聚焦只弹开输入框、不放光环（被动交互不配冲击波）；发送后先拍旧页面，在原点蓄力——光环中线停在页面底边上方 50px，强度 `0.42 · 缓入(350ms) · (0.85 + 0.15·sin(2πt/1.1s))`，原点附近页面向内收 2.5px；回答到达后更新 DOM、拍新页面，从蓄力位置接着扩散。波前以内显示新页面、以外仍是旧页面，边界 `1 − smoothstep(−0.6, 0.6, x)`；增量取「最远角 − 650 + 0.8w」，保证结束时新页面完整盖满再撤掉画布。请求失败只把蓄力在 120ms 内淡掉，不放光环。
- 用法上学 glimm 的克制：只在值得写进更新日志的时刻用——AI 给出结果、提交、完成；悬停、聚焦、菜单、加载中、重复操作都不用。

## 常见错误

- 一环一弯：每道色环各自扭曲，看起来像水波纹；应该整个光环一块透镜。
- 分离太重，文字出彩边；红蓝只差 ±8%。
- 透镜一直弯到页面边缘，窗框跟着歪；最后 56px 要淡到 0。
- 光环画到工具栏上，或区域圆角处露出方角。
- 反光把文字和图标也点亮，或者把 1px 边框亮成一条粗光带。
- 快照和 DOM 字体不一致、带着伪元素缺失，光环一出现页面就跳一下。
- 主题切换时快照拍到过渡中间色，光环期间页面变成半深半浅。
- 静止时画布和 rAF 还在跑。

## 验收

- [ ] 深浅两种模式、所选配色下，光环经过时文字清楚、不出彩边。
- [ ] 光环从不画到工具栏上；区域圆角处干净；透镜宽度不超过色环。
- [ ] 触发方式和原点是用户选的那个；页面的功能和静止外观与之前完全一样。
- [ ] 只在光环可见时运行，静止时零开销；减少动态效果下只在原地淡入淡出。
- [ ] 增强版：迎光的弧顶有一道高光，颜色沿弧线流动；回答到达时新内容恰好在波前以内出现，结束时没有残留的旧内容，也没有跳变。
