# 012 · 消息气泡的材质与动效（探索版）

原帖：https://x.com/Kubai087/status/2118508433704169726（数值来自原帖随附的 Prompt）

## 原理

给 AI 对话里的消息气泡一种材质，再让动效跟着材质走：发送、长回复进来、从中间删除一条。六种材质各有精确数值，材质决定颜料、字体、背景，也决定弹簧手感和出入场方式。整段对话作为一个整体移动：每个气泡各自跟着弹簧走到新位置，没有谁单独演一段动画。

## 两种用法（开始前先问用户）

- 重做：单独做一个对话 demo，用一种材质把三段动效演一遍，带切换材质的标签。
- 改造：给现有聊天的气泡换上材质和动效，写进项目自己的代码和设计系统，消息数据、组件、消息加载方式都不变。

开始前先问用户选哪种，以及用哪一种或哪几种材质。

## 改造范围

默认只改气泡：材质（第 1、2 节）和动效（第 3、4 节，第 5 节的回复展开和逐词出字，第 6 节气泡的长按和退场）。图标一律不动；自定义光标只属于重做 demo。下面三样各自单独问、一次问一个，用户同意才改：

- 输入区：输入框和发送按钮；
- 消息菜单：外观、菜单项、开合方式；
- 输入中指示器：换成第 5 节的点阵。

## 0. 从现状出发（改造）

- 找到对话列表、气泡组件、所有新增/编辑/删除消息的地方，记下输入区、消息菜单、输入中指示器。列出列表怎么布局、怎么滚动，以及现有的每个动画。
- 标出：新消息进来或离开时整段跳动；气泡动画过程中文字重新换行；任何动画了 `top`、`height`、`margin` 的地方。

## 1. 气泡盒子（所有材质相同）

- 文字 28px、行高 38px、`letter-spacing: -0.01em`，`padding: 17px 26px`，2px 边框（材质没给颜色就透明），圆角 38px：单行是胶囊，换行后是圆角矩形。只用普通圆弧，不用超椭圆或 `corner-shape`。发送按钮是圆形。
- 自己的在右，对方（AI）在左，距两侧 48px。长消息在固定宽度内换行（这里是 680px），从一开始就按这个宽度排版。
- 同一发送者连续的消息是一组：组内间距 4px，组间 16px。给每个气泡标 single / first / middle / last，有消息加入或离开时用 200ms 的 `border-radius` 过渡重塑整组：
  - Aqua、拟物、Cirrus：组内两个气泡相接处，发送者那一侧的角收成 10px。
  - 纯色、渐变：每个气泡都保持全圆；只有组内最后一个带尾巴，用发送者一侧底角的两个伪元素画（下面是自己的，对方的左右镜像）：

```css
.bubble::before { bottom: -2px; right: -14px; width: 64px; height: 38px; background: <气泡颜色>;
  border-bottom-left-radius: 18px 14px; border-bottom-right-radius: 3px; }
.bubble::after { bottom: -2px; right: -34px; width: 32px; height: 42px; background: <页面背景>;
  border-bottom-left-radius: 20px 24px; }
```

  色块伸出 12px，旁边的「挖口」把它切成一个卷。气泡成为组内最后一个时，尾巴用 160ms 淡入。

## 2. 六种材质

每种材质设定颜料、字体和背景（重做 demo 里还包括输入区、菜单和光标），全部做成 token。改造时用气泡的数值；背景只在材质离不开它时才用（Cirrus 需要天空，渐变需要深色背景），并且先问用户。下面的 CSS 是精确值，照抄才能还原。`.me` 是自己的气泡，`.them` 是 AI 的；基础字体 Inter。

### Cirrus（轻盈、干净）

没有边、没有阴影的薄磨砂玻璃，背后是蓝天。

```css
.bubble { border-color: transparent; background: none; box-shadow: none;
  backdrop-filter: blur(26px) saturate(130%); }
.bubble::before { content: ''; position: absolute; inset: -2px; border-radius: inherit;
  background: var(--grain), var(--tint); }   /* 文字在它上面 */
.bubble.me { --tint: rgb(46 128 232 / 0.34); color: rgb(255 255 255); }
.bubble.them { --tint: rgb(104 134 168 / 0.34); color: rgb(255 255 255); }
```

- `--grain`：160px 的 SVG 平铺，`feTurbulence type="fractalNoise" baseFrequency="0.9" numOctaves="2" stitchTiles="stitch"`，再接 `feColorMatrix "0 0 0 0 0.5  0 0 0 0 0.5  0 0 0 0 0.5  0 0 0 0.09 0"`（9% 的中灰）。
- 天空：只渲染一次，按页面两倍尺寸出图再当图片用。每个像素一条光线：眼睛高 1.25，沿 z 看，焦距 1.25，略微朝下（`uv.y - 0.02`），穿过云层步进：
  - 密度 `clamp(2.8 * fbm(p * 0.95) - 1.05 - 0.75 * p.y, 0, 1)`，fbm 是 6 个八度的值噪声（每个八度频率 ×2.03、权重减半）。
  - 步长取 0.03 和当前距离的 2.5% 中较大者，最多 160 步，或直到不透明。
  - 有云的每一步：`light = clamp((d - density(p + 0.25 * sun)) / 0.4, 0, 1)`，太阳方向 `normalize(-0.35, 0.75, 0.55)`；颜色 `mix(rgb(0.5, 0.6, 0.74), white, 0.2 + 0.8 * light)`，再按密度向 `rgb(0.9, 0.93, 0.97)` 混 25%；alpha = `0.6 * density`；按 `1 - exp(-0.0016 * t * t)` 融进天空。
  - 背后的天空：地平线 `rgb(0.66, 0.82, 0.97)` 到头顶 `rgb(0.15, 0.45, 0.9)`，按 `clamp(rd.y * 1.6 + 0.35, 0, 1)^0.85` 混合，再加一点朝太阳方向的暖光。
  - 结果是头顶深蓝、下半部分一片白色积云。图片缓慢左右漂移（每边 100px，每个循环摆一次）。
- 菜单：`background: var(--grain), rgb(70 98 134 / 0.52); backdrop-filter: blur(36px) saturate(130%)`；白字；删除 `rgb(255 138 126)`。

### 像素（复古游戏）

用 canvas 画在固定的 4px 网格上，不用 DOM 画气泡。

- 每一帧，用每个格子的中心去测气泡当前的形状：位置、缩放、尺寸，圆角半径 16px（组内相接处 4px），组内最后一个带阶梯尾巴：在气泡自己的坐标系里，原点是发送者一侧的底角，x 朝外，三角形 `-10 <= x <= 14, -16 <= y <= 0, y >= -16 + (x + 10) * 16 / 24`。在形状内的格子填色；在形状内、但有邻格在外的格子是一格宽的描边。
- 描边 `rgb(14 15 34)`；填色自己的 `rgb(93 112 232)`，对方的 `rgb(244 243 236)`。变暗时把填色向背景色混。
- 每个格子保存一个 `trace = max(trace * exp(-dt / 0.06s), 当前覆盖率)`，大于该位置的 4×4 Bayer 阈值才画（阈值 `(value + 0.5) / 16`，矩阵 `0 8 2 10 / 12 4 14 6 / 3 11 1 9 / 15 7 13 5`），所以移动的气泡会留下抖动的拖影。trace 小于 1 时，颜色按 `0.25 + 0.75 * trace` 向背景混：拖影保持大小但颜色浅。canvas 用 `image-rendering: pixelated` 放大。
- 背景 `rgb(27 30 52)`，横竖每 4px 一条 1px、3.5% 白的线。
- 文字留在 DOM 里：`font-family: 'Pixelify Sans'; letter-spacing: 0.02em`；自己的白字 `rgb(255 255 255)` 加 `text-shadow: 0 4px 0 rgb(14 15 34 / 0.35)`；对方的 `rgb(14 15 34)`；文字位置对齐到 4px 网格。
- 输入区、菜单、标签：直角，背景 `rgb(244 243 236)`，阶梯描边 `box-shadow: 0 -4px 0 rgb(14 15 34), 0 4px 0 rgb(14 15 34), -4px 0 0 rgb(14 15 34), 4px 0 0 rgb(14 15 34)`；发送按钮 `rgb(93 112 232)`。

### Aqua（俏皮、怀旧）

```css
.bubble { border-color: var(--edge); background: var(--face);
  box-shadow: inset 0 -14px 18px -8px var(--glow), inset 0 2px 2px rgb(255 255 255 / 0.5), 0 4px 8px -2px rgb(0 30 80 / 0.32);
  font-family: 'Lucida Grande'; letter-spacing: -0.01em; }
.bubble.me { --face: linear-gradient(180deg, rgb(116 188 255) 0%, rgb(58 146 242) 48%, rgb(28 111 220) 54%, rgb(43 132 236) 78%, rgb(138 210 255) 100%);
  --edge: rgb(21 80 160); --glow: rgb(160 228 255 / 0.95); color: rgb(255 255 255); text-shadow: 0 -1px 1px rgb(0 40 110 / 0.45); }
.bubble.them { --face: linear-gradient(180deg, rgb(253 253 254) 0%, rgb(236 238 241) 48%, rgb(220 223 228) 54%, rgb(228 231 235) 78%, rgb(251 252 253) 100%);
  --edge: rgb(141 148 159); --glow: rgb(255 255 255 / 0.95); color: rgb(29 29 31); text-shadow: 0 1px 0 rgb(255 255 255 / 0.7); }
.bubble::before { content: ''; position: absolute; top: 3px; left: 16px; right: 16px; height: min(46%, 36px);
  border-radius: 30px 30px 18px 18px; background: linear-gradient(180deg, rgb(255 255 255 / 0.92), rgb(255 255 255 / 0.12)); }
```

背景：`repeating-linear-gradient(180deg, rgb(246 246 246) 0 3px, rgb(233 233 233) 3px 6px)`。

### 渐变（品牌感）

```css
.bubble.me { --grad: linear-gradient(180deg, rgb(11 127 134) 0%, rgb(13 148 136) 28%, rgb(16 163 127) 60%, rgb(31 191 143) 100%);
  background: var(--grad) 0 calc(-1 * var(--top)) / 100% var(--thread-height); color: rgb(255 255 255); }
.bubble.them { background: rgb(38 38 42); color: rgb(244 244 245); }
.bubble { font-weight: 500; letter-spacing: -0.015em; }
```

`--top` 是气泡当前在对话里的偏移，移动时每帧更新，所以每个气泡显示自己高度上的那一段，上移时颜色跟着变；自己气泡的尾巴显示气泡底部那一段。背景 `rgb(0 0 0)`。发送按钮：`linear-gradient(160deg, rgb(31 191 143), rgb(13 148 136) 60%, rgb(11 127 134)) border-box`。

### 拟物（温暖、有触感）

```css
.bubble { font-family: 'Avenir Next'; font-weight: 500; }
.bubble.me { border-color: rgb(18 22 31); background: linear-gradient(180deg, rgb(72 81 100) 0%, rgb(39 48 66) 100%);
  box-shadow: inset 0 2px 0 rgb(255 255 255 / 0.18), inset 0 2px 6px rgb(255 255 255 / 0.08), inset 0 -2px 0 rgb(0 0 0 / 0.22),
    0 2px 4px rgb(15 23 42 / 0.18), 0 10px 22px -8px rgb(15 23 42 / 0.36);
  color: rgb(255 255 255); text-shadow: 0 -2px 0 rgb(0 0 0 / 0.28); }
.bubble.them { border-color: rgb(15 23 42 / 0.14); background: linear-gradient(180deg, rgb(255 255 255) 0%, rgb(242 243 245) 100%);
  box-shadow: inset 0 2px 0 rgb(255 255 255), inset 0 -2px 0 rgb(15 23 42 / 0.06), 0 2px 4px rgb(15 23 42 / 0.06), 0 8px 18px -8px rgb(15 23 42 / 0.18);
  color: rgb(31 41 55); text-shadow: 0 1px 0 rgb(255 255 255); }
```

背景 `rgb(245 242 233)`。

### 纯色（默认）

```css
.bubble.me { background: rgb(10 132 255); color: rgb(255 255 255); }
.bubble.them { background: rgb(233 233 235); color: rgb(0 0 0); }
```

无阴影，白色背景。

## 3. 整段对话一起动

- 对话从下往上排，在输入区上方；每个气泡用 `transform: translateY` 定位。新增、删除或尺寸变化时，算出每个气泡的新位置，让它们各自从当前位置沿自己的弹簧走过去。其他气泡不需要单独的动画。列表必须留在普通文档流里时，用 FLIP 做同样的事。
- 弹簧（response, damping）：Cirrus 0.5s 0.88，像素 0.42s 0.8，Aqua 0.46s 0.74，渐变 0.52s 0.92，拟物 0.34s 0.84，纯色 0.42s 0.86。
- 不动画 `top`、`height`、`margin`；任何时候两个气泡都不能重叠。

## 4. 发送

气泡从自己位置下方约 40px 升上来，按材质的方式出现：

- Cirrus：清玻璃起雾：背景模糊和着色在 560ms ease-out 内从 0 到满，scale 0.94→1 用 420ms，淡入 200ms。
- 像素：scale 0.3→1，380ms，`cubic-bezier(.22, 1, .36, 1)`，在网格上一格一格变；透过抖动在 200ms 内淡入；接近满尺寸时文字才出现。
- Aqua：果冻：scale 0.5→1 走弹簧（response 0.5s, damping 0.5），同时宽高反向晃动，一开始相差 12%，约 0.2s 内衰减掉；高度不超过自身的 1.04 倍，免得碰到上面的消息。
- 渐变：从失焦到清晰：blur 16px→0、scale 0.96→1，440ms，`cubic-bezier(.22, 1, .36, 1)`；淡入 300ms。
- 拟物：像按键：scale 1.1→1 走弹簧（response 0.36s, damping 0.55），先沉到 1 以下再回来。
- 纯色：scale 0.9→1，380ms，`cubic-bezier(.22, 1, .36, 1)`；淡入 120ms。

## 5. 长回复

- AI 输入中时，单独显示一个小点阵，不套气泡：约 48px 见方，放在回复将要开始的位置。每种材质在上面跑一小段物理，循环播放：
  - Cirrus 6×6：一股热沿慢圆周释放（2.2s 一圈），像热一样扩散：过去一秒内留下的高斯之和，越旧越宽、越淡。
  - 像素 6×6：从顶部中间挂下的单摆，角度 `0.9 cos(2πt / 1.1s)`，摆锤亮、摆杆淡，用方点、四级亮度。
  - Aqua 5×5：每 0.9s 一滴水落下，水波向外传开并消失（半径减时间的指数衰减余弦）。
  - 渐变 6×6：两盏一样的灯绕中心转，1.3s 一圈，颜色在网格上从薄荷绿过渡到青色。
  - 拟物 4×4：一颗弹跳的球：两次落地间（间隔 0.62s）是时间的抛物线，同时匀速横向漂移，碰墙折返。
  - 纯色 5×5：拨动的弦：基频加一个频率加倍、更弱的二阶模态。
- 每个都写成时间的平滑函数，亮度连续变化，不是开关。会动的加运动模糊：每帧在一个短快门（1/30 到 1/20 秒）内取平均。点是平的，每种材质一种在背景上醒目的颜色，静止时淡、亮起时满；不加高光或斜面。
- 回复到达时，气泡出现在点阵所在的位置，从那个角展开到消息的尺寸，点阵同时淡出：Cirrus 用软弹簧 640ms；Aqua 用略微过头的弹簧 760ms；拟物用短弹簧 520ms；其他 520–600ms，`cubic-bezier(.22, 1, .36, 1)`。文字已经排好版，用裁剪露出来，绝不重新换行。上方的对话直接跟着展开中的气泡走，而不是走弹簧，避免重叠。
- 词一个接一个进来，从 160ms 开始：
  - Cirrus：上升 10px 并淡入，间隔 18ms，每个 360ms；
  - 像素：直接打出来，间隔 26ms；
  - Aqua：从 0.4 弹出，`cubic-bezier(.34, 1.56, .64, 1)`，间隔 16ms，300ms；
  - 渐变：从 8px 模糊变清晰并上升 6px，间隔 14ms，320ms；
  - 拟物：从 1.14 盖章落下，间隔 22ms，160ms；
  - 纯色：淡入，间隔 14ms，240ms。

## 6. 从中间删除

- 长按：气泡先被按到 0.94–0.97，再抬到 1.02–1.04，其他气泡变暗到 35–50%（渐变还要模糊 4px）。菜单在气泡下方、气泡那一侧打开，菜单项依次是复制、重新生成、朗读、删除（删除为红色），按材质的方式出现：起雾（Cirrus）；从上往下分五步阶梯展开（像素）；从 0.7 弹出（Aqua）；从 12px 模糊对焦（渐变）；从上方 14px 落下走弹簧（拟物）；从 0.88 放大（纯色）。
- 点删除后菜单在 160–200ms ease-in 内离开，气泡按材质的方式消失：
  - Cirrus：退回清玻璃再淡出，420ms；
  - 像素：碎成格子，按打散的顺序瞬间消失，不留拖影，360ms；
  - Aqua：鼓到 1.14 然后破掉，320ms；
  - 渐变：放大到 1.12 并溶进 24px 模糊，380ms；
  - 拟物：先按到 0.94，再下落 36px 并淡出，不加模糊，320ms；
  - 纯色：缩到 0.7 并加 8px 模糊，260ms。
- 气泡一开始离开就移出布局。上方的消息落进空位，下方的不动：离空位最近的约 60ms 后先动，再往上每条比下面一条晚 50–80ms。每条都落在下面那条上：到达位置时如果还在往下走，速度反向并保留 20–45%（Aqua 最多，渐变最少），所以会轻轻弹起一点，绝不陷进下面那条。空位两侧是同一发送者时，合并成一组。

## 7. 保持正确

- 只动画 `transform`、`opacity`、`filter`（玻璃用 `backdrop-filter`）。
- 新操作从当前状态打断正在进行的动画，任何东西都不等动画播完。动画中途切换材质：对话淡出，再以新材质从当前状态淡入。
- 尊重 `prefers-reduced-motion`：保留淡入淡出，去掉位移、缩放和模糊，输入中点阵停在一帧静止画面，对话直接放到位。
- 消息进来时对话保持贴底，除非用户已经往上滚了。

## 实现提示

- 参考实现见 `assets/012-chat-bubble.html`（重做形态：1080×930 的逻辑画布按容器宽度整体缩放；气泡位置、弹簧、补位回弹、像素 canvas、点阵都由一个 rAF 循环驱动；Cirrus 天空用 WebGL 分条渲染一次）。
- 项目里已经用 `@property` 注册过 `--top` 之类同名变量时要改名，否则长度值无效、渐变背景直接消失。
- 逐词拆成 inline-block 后，浏览器的避头尾会失效：拆词时把标点并进前一个词。

## 验收

- [ ] 气泡盒子、分组间距、组内圆角或尾巴与第 1 节一致，加入或离开时 200ms 重塑。
- [ ] 六种材质的 CSS 与第 2 节逐值一致；Cirrus 有云海天空，像素由 canvas 按 4px 网格绘制并带抖动拖影。
- [ ] 新增、删除、尺寸变化时整段对话各自走弹簧，任何时候不重叠。
- [ ] 发送、点阵、回复展开、逐词、长按菜单、删除都按材质区分，时长和曲线与第 4–6 节一致。
- [ ] 删除后上方由近及远依次落下并轻微回弹，下方不动，同发送者合并成组。
- [ ] 减弱动态效果时只剩淡入淡出，点阵静止，对话直接到位。
