# 014 · 删除特效：燃烧、火焰、碎块、撕贴纸

原帖：https://x.com/Kubai087/status/2119831380276523207（第 1–9 节数值来自原帖随附的 Prompt）

## 原理

删除一张卡片或一行时，用一种离场方式把它的「画面」送走，周围的条目跟着反应，然后空位合拢。数据照常立即删除，特效只是一张快照在演出，不阻塞输入，也不等动画结束再提交。

四种离场，一个产品通常只选一种：

| 效果 | 气质 | 适合 |
|---|---|---|
| Burn 燃烧 | 决绝、戏剧化 | 永久删除 |
| Plume 火焰 | 温和、正向 | 完成、归档 |
| Blocks 碎块 | 俏皮 | 轻量、游戏化的产品 |
| Peel 撕贴纸 | 实体感 | 标签、贴纸样的条目 |

每条路线都是同样四件事：条目的快照；逐像素着色器（Burn、Plume）；真正的网格（Peel——折起来同一位置有两层，逐像素扭曲做不到）；大量小四边形（Blocks 和粒子）。

## 范围

这是对用户现有产品的改造，不是做 demo：在用户的代码、技术栈、组件、token 和列表里做。不改变删除做了什么，不改变列表静止时的样子；不照搬演示场景（手机框、背景、样例卡片、字体）；不重写列表，新增依赖或渲染器先问。下面的数值都是起点，按 432 × 130 的条目给出，第 1 节说明怎么换算。

## 开始前先问用户（一次问一个，给出默认值，等回答）

先看现状（第 0 节），用几行告诉用户看到了什么，然后依次问：

1. 范围：哪些删除动作有特效（默认：条目自己的删除按钮）；左滑删除和批量删除怎么办（默认：保持现状，或用第 8 节的淡出）；有没有撤销。
2. 效果：选哪一种，并说明哪一种最适合用户条目的形状和尺寸。
3. 邻居：周围条目要不要反应（第 7 节，默认要）；要不要热浪扭曲，在用户平台上代价是什么。
4. 颜色和模式：贴纸背面用条目自己的分类色还是品牌色；Plume 的火焰色照用还是取自用户调色板；应用有哪些模式。

问完给出在用户平台上的方案：改哪些文件、怎么接进列表、怎么拍快照、用什么画、代价和降级。等用户同意再动手。

## 0. 从现状出发

- 列表、条目组件、删除发生在哪里、现在列表怎么重排、有没有现成的离场动画或列表动画库。能做第 2 节弹簧的，补位就复用它。
- 条目的真实样式：尺寸、圆角和圆角曲线、背景、边框、阴影，有没有图片、视频、内嵌滚动。
- 滚动容器、裁剪或变换列表的祖先、压在列表上的东西（标题栏、标签栏、悬浮按钮），列表是否虚拟化或复用。
- 条目用什么绘制，产品已有哪些图形能力（WebGL、three.js、Pixi、Skia、Metal、Vulkan、wgpu），平台版本范围——这决定快照和渲染器（第 9 节）。
- 动效 token、颜色 token、深色模式、减少动态效果的处理、测试和截图怎么跑，都要保持可用。

## 1. 适配用户的界面

- 尺寸系数 `k = clamp(sqrt(w·h / (432·130)), 0.6, 1.4)`，像素距离和火焰高度乘 k。Burn 的场本来就相对条目；网格单元保持 5–6px。
- 明显小于 200 × 60 的条目：用 9 / 18px 块的 Blocks，或淡出。整行宽的表格行：Burn、Blocks、Peel；Plume 需要高度，给矮一点的火焰，让它越过上一行。
- 形状：所有算边缘的地方（快照、贴纸的模切白边、火焰裁剪）都用用户的圆角和圆角曲线；连续圆角用 `|x|ⁿ + |y|ⁿ = 1`，和 CSS 或平台 API 同一条曲线。方行半径 0。
- 纸色：特效读条目自己的画面，有色条目烧焦前保持原色。半透明或模糊背景要在快照里压平到真实背景上。
- 深色（起点，肉眼校正）：Burn 的焦黑在深色上看不见，提到 `rgb(58 50 46)` 并保留灰烬线；邻居的火光约一半强度、正常混合（multiply 在深色上无效）；Plume 光晕 20%；Peel 阴影 50% 纯黑，残胶 12%。
- 起点：Burn 和 Blocks 从真实删除控件处开始；Peel 从离控件最近的角开始，朝条目远端走，方向选让翻起的部分留在屏幕内的那个；控件在左侧就镜像。
- 挂载位置：特效画布挂在滚动容器那一层、列表之外，删掉条目不会把它卸载，裁剪和列表一致；特效期间列表滚动，画布内容跟着移动。

## 2. 共用部分

- 删除处理函数里、改状态之前：读条目矩形 → 拍快照 → 隐藏真实条目。虚拟化或复用列表下一次更新条目就没了，所以必须先做。
- 特效画在列表上方一张不接收输入的画布上。标题和导航在画布之上，火焰从它们背后经过；可以短暂盖住相邻条目，只被滚动区或屏幕裁剪。
- 第一帧必须和真实条目完全一致（包括圆角曲线），否则就是快照错了。按 2× 或设备像素比上传，预乘 alpha；改色前先反预乘。
- 补位：只用 transform 的弹簧 `progress = 1 − e^(−7t)·cos(6t)`，520ms，绝不动画 height 或 margin。补位在特效还没结束时就开始：Burn 900ms、Plume 720ms、Blocks 240ms、Peel 640ms。列表若补进一个新条目，它从下方 60px 处上来，在前 40% 淡入。不要把刚删的文字带回来。
- 只在特效运行时绘制，结束释放缓冲和纹理。每次删除各有自己的特效，最多同时 3 个，超出用淡出。撤销时立即停掉那个特效，条目按产品原有方式回来。
- 场：`f(p) = length((p − click)·(1, 1.15)) / maxD + (fbm(p·0.018) − 0.5)·0.42 + (fbm(p·0.085) − 0.5)·0.05 − pocket`。click 为删除按钮中心，maxD 为它到最远角的距离；fbm 是 5 个八度的平滑值噪声，每级频率 ×2.03 并加偏移 17.1、权重减半；`pocket = smoothstep(0.6, 0.78, fbm(p·0.03 + 40))·0.12`。粗场去掉最后两项。

## 3. Burn（共 2s，燃烧前沿 1.15s）

`level = t/1.15·1.4 − 0.1`，`d = f(p) − level`，正值表示还没烧到。绘制顺序：背光 → 纸 → 火焰 → 粒子。

- 背光：前沿周围的页面上，`rgb(255 158 56)`，强度 `exp(−|d|/0.07) · near · 30%`；near 在条目上为 1，条目外为 `exp(−距离/26)`；level 从 1.1 到 1.3 时淡出。
- 纸，依次：d 从 0.17 到 0.05 混向 `rgb(247 194 102)` 55%；d 从 0.06 到 0.008 混向 `rgb(107 51 18)`；d 从 0.012 到 −0.006 混向 `rgb(13 9 8)`。焦黑保持干净：一条占场宽 5%（约 20px）的带，从暖黑到 `rgb(43 31 26)`，边缘只随慢噪声游走 `charD = d + (noise(p·0.05) − 0.5)·0.014`；末端一条 `rgb(189 179 168)` 85% 的细灰烬线（`|charD + 0.05| < 0.0035`）。线之后纸就没了，边缘利落。不要灰色斑驳，不要烟雾状软边。
- 热色在未烧的一侧，焦黑保持暗。每条带 `exp(−(d/w)²)`，w 分前（d>0）后（d<0）：橙 `rgb(255 112 13)` w 0.05 / 0.012，92%；金 `rgb(255 204 66)` w 0.024 / 0.006，95%；亮线 `rgb(255 250 214)` w 0.008。全部乘 `0.72 + 0.28·noise(p·0.02，以 1.5/s 移动)`。
- 前沿前方零星火星：`smoothstep(0.78, 0.84, noise(p·0.17))`，只在 d 约 0.02–0.15，`rgb(255 184 64)`，闪烁 `0.6 + 0.4·sin(18t + noise(p·0.05)·30)`。
- 火焰从前沿升起：`n1 = noise(x·0.045 + 0.6t, y·0.02 + 6t)`，`n2 = noise(x·0.11 + 5, y·0.05 + 9t)`，`tall = 16 + 72·smoothstep(0.32, 0.8, n1)`。每点向下取 5 个样本 s ∈ [0, tall]，累加 `exp(−(粗场前沿/0.042)²) · (1 − smoothstep(0, tall, s)) · 0.5`，只算落在条目上的样本（`smoothstep(2, −6, 到边缘的距离)`）。上限 1，再乘 `smoothstep(0.2, 0.62, 0.7·n1 + 0.3·n2)` 分成一条条火舌。色带 `rgb(255 107 18)` → 0.2–0.55 到 `rgb(255 194 51)` → 0.55–0.9 到 `rgb(255 250 214)`；alpha `smoothstep(0.03, 0.62, flame)·95%`。
- 纸是网格（6px 单元）：`lift = clamp(1 − (f − level)/0.1, 0, 1)²`，背离 click 后缩 `9px·lift`，上升 `12px·lift²`，颜色向 `rgb(209 194 173)` 过渡。
- 64 个粒子，前沿到达时离开，寿命 0.5–1.2s。80% 是 2.5–4.5px 的火星，`rgb(255 158 41)` 到浅色内核；其余是 3–8px、60% 的浅灰碎屑，轮廓不规则。上升 60–240px（火星 ×1.2，碎屑 ×0.8），横向漂 `sin(6·age)·12·age`、最多 20px，寿命 45% 后开始淡出。

## 4. Plume（1.4s）：一团柔软的火焰从下往上带走条目

- 纸从下往上消失：边线 0.04s 起 ease-in-out，0.84s 到顶；边缘游走约 17px，中段比两侧最多领先 80px（行程中段最大）。边线以上 90px 内，纸暖化到 `rgb(255 212 173)`，最多上移 20px，向中线收拢 20% 并晃动，像被吸进火焰根部；最后 10px 淡出。
- 一团火焰，一个着色器，起点在条目底边中点：根部窄，半宽 36–62px，往上每高 1px 加宽 0.75px，越往上越开。不能底部最宽，否则像一块方块。高度 90–300px，0.16s 内长出，脉动约 10%。越高摆得越多：`sway = sin(3.6t + up·0.012)·up·0.08 + sin(6.1t + up·0.03)·up·0.03`，`fan = (x − 中线 − sway) / (半宽 + up·0.75)`。
- 形状：`m = 1 − length(fan, rel) − (v.x − 0.35)·0.3`，m > 0 处绘制。冠部尖舌沿着冠走：`rel = (up/高) / (0.86 + 0.5·c1² + 0.18·c2²)`，`c1 = 1 − |sin(fan·3.4 + 2.6t + sin 1.7t)|`，`c2 = 1 − |sin(fan·7.1 − 4t + 1.3)|`。
- 火瓣：Voronoi，`q = (fan·2.4, (up + 20)^0.8·0.02 − 2.6t)`，最多 0.58 的噪声扭曲，特征点以 3.2 rad/s 绕圈；v.x 为到最近点距离，v.y 为到次近点距离。这样分扇后瓣边是从根部升起的长弧线。底边扇贝状：`smoothstep(0, 1, (rise + 14 − v.x·46)/12)`。
- 颜色：粉 `rgb(250 153 168)` 与橙 `rgb(255 168 87)` 按柔和噪声分块，每瓣中心向 `rgb(255 204 163)` 提亮；`v.y − v.x` 小于 0.04–0.075 处为叶脉 `rgb(255 240 158)`；下半部分一颗近白的芯 `rgb(255 247 214)`；外圈 `rgb(255 184 143)` 30% 光晕。
- 0.25s 起每 0.13s 掉下一片，共 6 片，椭圆 26 → 6px，0.55–0.85s 内上浮 120–240px。44 个浅色圆点 `rgb(255 237 189)`，4–12px，0.15–0.85s 间升起。
- 0.72s 起快速燃尽，而不是整块飞走：`gone = smoothstep(0.72, 1.16, t)`；高度 ×`(1 + 1.3·gone²)`，半宽 ×`(1 − 0.6·gone)`，上部扩张 0.75 → 0.32，摆动最多 ×2.2；从根部开始碎开（m 减去 `gone·(1.25 − 0.55·rel)·(0.55 + 0.45·noise)`），尖端最后消失。根部只上升 `150px·gone²`。

## 5. Blocks（1.5s）

- 先 70ms 撞击：条目放大 4%，最多闪 55% 白，`sin(π·t/0.07)`。
- 然后在 36px 网格上切块：35% 保持整块，45% 切成 18px，20% 切成 9px。每块显示条目自己的那一片，1px 20% 描边，下沿和右沿 5px 内最多暗 36%，各自 92–100% 的明度，看起来是实心的。
- 从中心同时炸开，最多 30ms 错开。方向 `normalize((from − center − (0, 14))·(1, 2.2) + 最多 20px 随机)`；速度 `(200 + rand·400 + 220·nearness)·(1.25 − size/72)`，再加 430 向上；重力 2300 px/s²；旋转最多 6 rad/s。
- 落在可见列表底边（26px 内），弹一次：竖直 42% 速度、横向保留 60%、旋转保留 40%；0.95–1.25s 后缩到 20% 并淡出。
- 补位：列表能从上方补进条目时，上方条目带弹跳落下，新条目 90ms 后从顶上掉进来，700ms：`(t/0.5)²` 下落到一半落地，然后 10%（t 0.5–0.76）和 3%（t 0.76–1）两次回弹。否则用第 2 节的弹簧。

## 6. Peel（1.2s，撕起 0.62s）

- 条目是网格（5px 单元），弯过一根半径 20 的圆柱。圆柱线从角上出发，沿 `normalize(−0.55, 1)`（控件在右上时）扫过条目，0.62s 到达对角。线的位置 `reach·p²·(1.6 − 0.6p)`：起步慢，最后一点胶松开时加速，贴纸不会停顿后才脱落。
- 线后方距离为 e 的点：弯曲角（1.3 增到 1.8 rad）以内贴着圆柱 `along = line − r·sin(e/r)`，`z = r·(1 − cos(e/r))`；之后接一段半径 420 的大弧，与圆柱末端切线连续。两段都保持弧长，不拉伸，被拉起的角以 `(1 − cos 弯曲角)` 倍线速移动。透视焦距 1400，以屏幕中心为中心，不以条目为中心。
- 绘制顺序：残胶（34% 白，2px 网格斑点，脱落 0.3s 后消失）→ 未撕起部分 → 阴影 → 翻起部分。翻起部分的单元从粘着端到自由端依次画，不用深度缓冲也能让折叠的上层盖在上面。
- 阴影落在屏幕平面：偏移 `(0.14, 0.22)·z`，不加透视；边缘柔化 `8 + 0.24·z`；不透明度 `34% / (1 + z/170)`，在最初 14px 高度内从 0 升起。阴影也落在未撕部分上。折痕处未撕部分再暗 16%，距弯折线 16px 内淡出。
- 一盏灯 `(−0.35, −0.55, 0.76)`，法线 `(dir·sin 弯曲, cos 弯曲)`，背面翻转。漫反射 `0.74 + 0.26·max(n·L, 0)/L.z`；Blinn-Phong 高光指数 24、14%，在最初 0.5 rad 内渐入；脊线处（侧看）加边缘光 `(1 − |n.z|)⁵·50%`。
- 背面印条目颜色并调得更鲜活（饱和度 ×1.5，混 12% 白，明度 ×1.06），外圈 6px 白色模切边，沿条目自己的圆角曲线。这是它读起来像贴纸的关键。
- 点击时角自己翻起；只有产品里删除本身是拖拽或滑动时，才把线绑到手指上，角始终在手指下。
- 0.62s 贴纸脱落：取最后几毫秒质心的速度（平面内和高度）保持下去；位移 `v·g`，`g = (1 − e^(−5t))/5`（空气阻力），下落 `(1500/5)·(t − g)`，绕质心转 `2.4·g` rad，0.3–0.55s 淡出。

## 7. 邻居

每个条目知道自己在列表里的距离 d，影响按 `1/|d|` 衰减。只用 transform 和绘制作用在真实条目上，不改布局，不挡输入。

- Burn / Plume 火光：朝火一侧的边上一个 230px 宽的径向渐变，72% 处透明，**画进条目自己的填充里**（另叠一层同圆角的元素会在圆角处露出浅色边）。最近的 42%，下一个 10%，闪烁 `0.8 + 0.2·sin(31t)·sin(13t)`。Burn 的光跟着前沿走，Plume 停在中间；Burn `rgb(255 176 96)`，Plume `rgb(255 178 150)`。同时背离火焰倾 3px（Plume 7px）、缩小 0.6%。全部 150ms 渐入，在 1.4s（Plume 1.25s）的最后 350ms 渐出。
- Burn / Plume 热浪：以 170px/s 向上漂的噪声推动邻居和标题的像素（包括描边），横向最多 4px（Plume 5px），竖向约三分之一。下方条目 60%，标题 Burn 50%、Plume 70%。竖向噪声周期约 80px、单八度：整行文字平滑弯曲；周期更短会把单个字撕开。只在有火时开启；要看得出来，但绝不影响阅读。
- Blocks：被冲击推开再回弹：`18px·e^(−6.5t)·sin(24t)`，倾斜 `1.1°·e^(−6.5t)·sin(20t)`，挤压 `1.8%·e^(−9t)`，从 70ms 开始。
- Peel：撕起过程中被向贴纸拉 6px，脱落时回弹 `e^(−7t)·cos(26t)`。

## 8. 降级

- 减少动态效果：没有特效、没有邻居反应，220ms 淡出加 4% 缩小，然后空位合拢。
- 渲染器不可用、上下文丢失、同时超过 3 个：同上。
- 焦点移到下一个条目，读屏器听到「已删除」。

## 9. 按平台实现（起点，不是规定；优先用产品已有的）

- Web：一张 WebGL2 画布盖在列表上，Blocks 和粒子用实例化或批量四边形；产品已有 three.js、Pixi 之类就在那里画。在列表删除的地方接入：React / Vue 在点击处理里、状态更新之前读矩形并拍快照，补位用 Motion layout、`useLayoutEffect` 里的 FLIP 或 TransitionGroup；Svelte 用 `animate:flip`；Virtuoso、TanStack Virtual 等虚拟列表，画布必须放在虚拟列表外面。
  - 热浪，优先级从高到低：有 HTML-in-Canvas 时，把列表通过 WebGL 画出来，在火焰周围一个场里逐像素扭曲：火焰框内最强，向外按 170px 高斯衰减，向上的范围约为向下的两倍（渐进增强、特性检测、保留 DOM 布局；WebGL 上传接口在 Chrome 各版本间变过，用 `drawElementImage` 画到 2D 画布再上传更稳）。否则给每个邻居套 SVG 滤镜：`feTurbulence` baseFrequency `0.008 0.013`、单八度，红通道对比度加倍让位移均匀，`feOffset` 让它上移，`feDisplacementMap` scale 约为想要像素的 2.5 倍。位移不会平滑被移动的内容，所以要重建轮廓：结果膨胀 1px 垫在自己下面，再用自己 alpha 0.8px 模糊、斜率加倍后的形状裁一次。只在特效期间挂滤镜，Safari 要实测。都不行就不做热浪。
  - 快照：条目简单时，同步重画到 2D canvas（准确：文字位置读 Range 的矩形，字体、颜色、字距读计算样式）。HTML-in-Canvas 在新版 Chromium 的开关后可用，Firefox、Safari 暂无。html-to-image、modern-screenshot 在删除时拍一次，几十到几百毫秒，字体和图片要同源。html2canvas 是最后手段。
  - 没有 WebGL2：Blocks 可以用 Canvas 2D 的 `drawImage` 切片，几百块以内；其余退回淡出。
  - 代价：Burn 的火焰是最重的着色器，低端设备把前沿采样从 5 次降到 3 次，或这一层半分辨率绘制。
- iOS：快照用 `ImageRenderer` 或 `drawHierarchy`。UIKit 在数据源的删除里拿 cell 的 rect；SwiftUI 在删除动作里，覆盖层放在 List 之上。Burn、Plume 用 SwiftUI `.layerEffect`（iOS 17+），热浪用邻居上的 `.distortionEffect`。Peel 需要网格：Metal 或 SceneKit 平面。Blocks 用 `TimelineView` 里的 `Canvas`。iOS 17 以下：Blocks 和淡出。
- Android：快照用 `View.drawToBitmap` 或 Compose `GraphicsLayer.toImageBitmap()`。接 RecyclerView 的 `ItemAnimator`，或 Compose `Modifier.animateItem()`，特效放覆盖层。Burn、Plume、热浪用 `RenderEffect` + AGSL `RuntimeShader`（API 33+）。Peel 用 `Canvas.drawBitmapMesh` 按层依次画，或 OpenGL ES 做真透视。Blocks 用 `Canvas.drawVertices` 或按矩形 `drawBitmap`。
- Flutter：快照用 `RenderRepaintBoundary.toImage`（异步，按下时就拍或常备一张）。补位用 `AnimatedList.removeItem`，特效放 `Overlay`。Burn、Plume 用 Impeller 上的 `FragmentProgram`；Blocks 用 `Canvas.drawAtlas`；Peel 用带纹理的 `Canvas.drawVertices`。
- Rust：把条目渲染到纹理，用 wgpu：实例化四边形，Peel 一条网格管线，着色器移植到 WGSL。Bevy 用 `Mesh2d` + 自定义 `Material2d`；egui、iced 通过渲染器的 wgpu 回调画（控件自己做不到）；GPUI 渲染到自定义元素，或退回淡出。
- Electron、Tauri：走 Web 路线。Electron 能带上需要的 Chromium 特性；Tauri 用系统 WebView，macOS 和 Linux 上要在 WebKit 里实测 WebGL2 和热浪滤镜。
- 其他（Qt、游戏引擎、自研渲染器）：同样四件事，用它自己的着色器和网格工具。

## 10. 实现要点（demo 的做法）

- 结构：标题栏在画布之上（z-index 更高），火焰从它背后经过；画布覆盖滚动视口、`pointer-events: none`，每帧按 `scrollTop` 换算位置，列表滚动时特效跟着走。
- 快照同步重画：按圆角裁剪；元素的背景和边框画圆角矩形；`<svg>` 里的 `<path>` 用 `Path2D` 按 viewBox 缩放描边；文字逐字用 Range 取矩形、按 `fontBoundingBoxAscent` 定基线逐字 `fillText`，不会累积字宽误差。条目不用阴影、不用 line-clamp（省略号不在 DOM 里，快照画不出来），第一帧才能和 DOM 完全一致。
- 一个通用的 FLIP 补位：每个条目身上挂若干「偏移」记录 `{dy, 起点, 所属删除}`，删除时记录每个条目改动前后的 `offsetTop` 差作为新偏移、按效果延迟开始弹簧；撤销时先移除那次删除的偏移，再按「改动前的视觉位置 − 改动后的布局位置」补一条立即开始的偏移，正在等待或弹到一半的条目都能原地接上。
- 弹簧 `1 − e^(−7t)cos 6t` 在 520ms 时还有约 2.6% 的过冲残差，直接收住会跳 3–4px；demo 在最后 120ms 把残差平滑收掉。
- Burn 的纸是 CPU 生成的 6px 网格，顶点着色器里算 lift，片元着色器按未位移的坐标算颜色；背光和火焰是条目外扩一圈的四边形上的两种模式；粒子、Plume 的碎片和圆点、Blocks 的碎块共用一个「批量四边形」程序，CPU 每帧写顶点。
- Peel 的网格变形在 CPU 上算（约 2300 个单元），单元按 e 从小到大排序后绘制；阴影先以 MAX 混合画进半分辨率帧缓冲，再做一次可分离模糊、按当前最大高度定模糊半径，最后作为黑色叠上。
- 热浪：每个受影响的元素动态生成一个 SVG 滤镜（区域向下多留约 440px，供 `feOffset` 把噪声往上推），每帧更新 `dy` 和 `scale`，特效结束移除 `filter`。
- 淡出降级直接把快照 canvas 当成 DOM 元素放回原位，用 WAAPI 做 220ms 淡出加缩小，不依赖 WebGL。
- 参考实现见 `assets/014-delete-effects.html`（四种效果、邻居与热浪开关、深浅、¼ 速慢放、撤销）。

## 常见错误

- 先更新状态再拍快照：条目已经被卸载或复用，拍到的是别的东西。
- 快照和真实条目差一点（圆角、字体、基线），一删就跳一下。
- 用 height / margin 动画补位，整列重排，掉帧。
- 等特效播完才删除数据，或特效期间挡住输入。
- 焦黑做成灰色斑驳或烟雾软边，看起来脏；或者深色模式下焦黑和背景融成一片。
- Plume 底部最宽，像一个方块在烧；燃尽时整团飞走，而不是从根部碎开。
- Peel 用逐像素扭曲：折叠处只能显示一层；或者单元绘制顺序反了，折叠的下层盖在上层。
- 火光用单独一层叠在邻居上，圆角处露出浅色边。
- 热浪噪声周期太短，把字撕碎；或者没有火的时候滤镜还挂着。
- 静止时画布、rAF、纹理还在。
