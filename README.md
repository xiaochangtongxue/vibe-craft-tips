# vibe-craft-tips

一个 [Claude Code](https://claude.com/claude-code) skill：18 条让 Vibe Coding 做出来的界面更有质感的 UI 细节规范。每条都给出具体数值，并附一个可以直接打开操作的参考实现页面。

内容整理自 [枯白啃设计 @Kubai087](https://x.com/Kubai087) 的系列帖子《999 个小技巧，让你 Vibe 的产品更有质感》001–018。技巧思路和数值归原作者所有，每条参考文件和页面里都附有原帖链接。

## 安装

```bash
git clone https://github.com/xiaochangtongxue/vibe-craft-tips ~/.claude/skills/vibe-craft-tips
```

## 使用

在 Claude Code 里让界面「更有质感」，或者要新做、改造其中某种组件和效果（拟物按钮、级联菜单、Toast、加载状态、删除特效、镭射卡片等）时，会自动用到这个 skill。条目索引见 [SKILL.md](SKILL.md)，所有参考实现页面的总目录在 [assets/index.html](assets/index.html)。
